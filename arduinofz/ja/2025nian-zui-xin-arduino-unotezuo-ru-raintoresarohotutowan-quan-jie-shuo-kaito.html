【2025年最新】Arduino Unoで作る！ライントレーサーロボット完全解説ガイド

はじめに：Arduinoでロボット製作を始める魅力

ロボット工学とプログラミングを学ぶ上で、Arduinoは最適なプラットフォームです。特に「ライン追跡ロボット（ライントレーサー）」は、センサー技術、モーター制御、論理思考を一度に学べる入門プロジェクトの決定版です。本記事では、Arduino Unoを使用したライン追跡ロボットの製作を、部品選定から配線、プログラミング、調整まで徹底的に解説します。このガイドを読み終える頃には、あなたの目の前でロボットがスムーズに黒い線を追いかける姿を確認できるでしょう。

1. ライン追跡ロボットの基本原理を理解する

ライン追跡ロボットは、床に描かれた「線（通常は黒色）」と「背景（通常は白色）」の反射率の違いを利用して進行方向を決定します。この仕組みを理解することが、製作の第一歩です。

  • 赤外線センサー（IRセンサー）: 赤外線LEDから光を照射し、その反射光の強度を受光素子で測定します。
  • 反射率の違い: 白い床は赤外線をよく反射し、黒い線は赤外線を吸収します。この電圧差をデジタル信号（0または1）に変換します。
  • 制御ロジック: センサーが「線」を検知したら、モーターの回転速度を左右で変え、ロボットの方向を修正します。
ポイント：センサーが「線の上」にいる時と「線の外」にいる時で、読み取り値が明確に変化するように距離感を調整することが、安定動作の秘訣です。

2. 必要な部品リストと選定のコツ

製作に必要な部品を揃えましょう。初心者の方は、初心者向けスターターキットを購入すると個別に揃えるよりも安価で済む場合があります。

必須パーツ

  • Arduino Uno ボード: マイコンの頭脳となる部分です。
  • モータードライバ (L298N または TB6612FNG): Arduinoの弱い電流ではモーターを直接回せないため、電力を供給するためのICです。
  • DCモーター ×2: 左右の駆動輪用。ギヤボックス付きのもの（TTモーター）が扱いやすいです。
  • 車輪 ×2: モーターに取り付けます。
  • ユニバーサルホイール（ボールキャスター） ×1: ロボットの後部を支えるための補助輪です。
  • ライン追跡センサーモジュール (TCRT5000): 赤外線センサーが2個搭載されたモジュールがおすすめです。
  • バッテリーボックス: 単三電池4本用（6V）または9V電池用。モーター用電源とArduino用電源を分けると安定します。
  • ジャンパーワイヤー: 配線用のオス-オス、オス-メスケーブル。
  • シャーシ（車体）: アクリル板や3Dプリント製のもの、あるいは段ボールで自作してもOKです。

あると便利な工具

  • はんだごて（センサーや配線の固定用）
  • ドライバー、結束バンド、両面テープ

3. 回路図と配線手順（ステップバイステップ）

配線ミスは故障の原因になります。電源を入れる前に、必ず配線を確認しましょう。以下に代表的な接続例を示します。

接続表（Arduino Uno と 各モジュール）

  • モータードライバ（L298N）:
    • IN1 → Arduino D8
    • IN2 → Arduino D9
    • IN3 → Arduino D10
    • IN4 → Arduino D11
    • ENA → Arduino D5（PWM制御用）
    • ENB → Arduino D6（PWM制御用）
    • 12V端子 → バッテリー（+）※6Vでも動作可能
    • GND → Arduino GND と バッテリー（-）を共通接続
  • ラインセンサー（TCRT5000 2チャンネル）:
    • VCC → Arduino 5V
    • GND → Arduino GND
    • OUT1（左センサー） → Arduino A0
    • OUT2（右センサー） → Arduino A1
  • モーター:
    • 左モーター → モータードライバ OUT1 と OUT2
    • 右モーター → モータードライバ OUT3 と OUT4
重要：モータードライバのGNDとArduinoのGNDは必ず共通にしてください。これがないと信号が不安定になり、モーターが誤動作します。

4. ロボットの動作を制御するArduinoスケッチ（プログラム）

次に、Arduino IDEに書き込むプログラムを作成します。このプログラムでは、センサーの状態を読み取り、以下の「状態遷移」に基づいてモーターを制御します。

制御ロジック（2センサー使用時）:

  • 状態1（両方白）: 直進
  • 状態2（左だけ黒）: 左に旋回（ロボットが右に外れたため）
  • 状態3（右だけ黒）: 右に旋回（ロボットが左に外れたため）
  • 状態4（両方黒）: 交差点または停止。ここでは直進とします。

サンプルコード（コピー＆ペースト用）

以下のコードをArduino IDEに貼り付け、ボードを「Arduino Uno」に設定して書き込みます。

※このコードはHTML表示用に整形しています。コピーしてそのまま使用可能です。

// ピン定義
#define ENA 5
#define ENB 6
#define IN1 8
#define IN2 9
#define IN3 10
#define IN4 11

#define SENSOR_LEFT A0
#define SENSOR_RIGHT A1

// モーター速度設定（0-255）
const int baseSpeed = 180; // 基本速度
const int turnSpeed = 120; // 旋回時の速度

void setup() {
  // モータードライバのピンを出力に設定
  pinMode(IN1, OUTPUT);
  pinMode(IN2, OUTPUT);
  pinMode(IN3, OUTPUT);
  pinMode(IN4, OUTPUT);
  pinMode(ENA, OUTPUT);
  pinMode(ENB, OUTPUT);
  
  // センサーを入力に設定
  pinMode(SENSOR_LEFT, INPUT);
  pinMode(SENSOR_RIGHT, INPUT);
  
  // モーターを初期化（停止状態）
  digitalWrite(IN1, LOW);
  digitalWrite(IN2, LOW);
  digitalWrite(IN3, LOW);
  digitalWrite(IN4, LOW);
  delay(1000); // 1秒待機してから開始
}

void loop() {
  // センサーの読み取り（LOW=黒線検知、HIGH=白床）
  int leftSensor = digitalRead(SENSOR_LEFT);
  int rightSensor = digitalRead(SENSOR_RIGHT);

  // 状態に応じた制御
  if (leftSensor == HIGH && rightSensor == HIGH) {
    // 両方白：直進
    forward();
  } else if (leftSensor == LOW && rightSensor == HIGH) {
    // 左が黒：右に外れたので左に旋回
    turnLeft();
  } else if (leftSensor == HIGH && rightSensor == LOW) {
    // 右が黒：左に外れたので右に旋回
    turnRight();
  } else {
    // 両方黒：交差点や太い線。直進を維持
    forward();
  }
}

// 直進
void forward() {
  digitalWrite(IN1, HIGH);
  digitalWrite(IN2, LOW);
  digitalWrite(IN3, HIGH);
  digitalWrite(IN4, LOW);
  analogWrite(ENA, baseSpeed);
  analogWrite(ENB, baseSpeed);
}

// 左旋回
void turnLeft() {
  digitalWrite(IN1, LOW);
  digitalWrite(IN2, HIGH);
  digitalWrite(IN3, HIGH);
  digitalWrite(IN4, LOW);
  analogWrite(ENA, turnSpeed);
  analogWrite(ENB, turnSpeed);
}

// 右旋回
void turnRight() {
  digitalWrite(IN1, HIGH);
  digitalWrite(IN2, LOW);
  digitalWrite(IN3, LOW);
  digitalWrite(IN4, HIGH);
  analogWrite(ENA, turnSpeed);
  analogWrite(ENB, turnSpeed);
}
注意：上記コードは一例です。モーターの配線方向によっては、forward関数で逆に進む場合があります。その場合はIN1～IN4のHIGH/LOWを逆にしてください。

5. 組み立てのコツと調整方法（キャリブレーション）

プログラムを書き込んだら、実際にロボットを組み立て、コース上でテストします。

組み立て手順

  1. シャーシにモーターと車輪を取り付けます。
  2. Arduino Unoとモータードライバをシャーシに固定します。
  3. センサーをロボットの前端に取り付けます。床からの距離は5mm～15mmが理想です。
  4. 前述の配線表に従って、すべての配線を行います。
  5. バッテリーを接続し、スイッチを入れます。

動作が不安定な場合の調整ポイント

  • センサーの感度調整: 多くのTCRT5000モジュールには可変抵抗（ポテンショメータ）が付いています。ドライバーで回して、白床でHIGH、黒線でLOWになるように調整します。
  • 速度の調整: baseSpeedの値を小さくすると安定しますが、遅くなります。まずは150程度から始め、徐々に上げてみましょう。
  • 旋回速度の調整: turnSpeedが遅すぎるとカーブで線を見失います。baseSpeedとのバランスを見ながら調整します。
  • センサー間の距離: 線の太さ（一般的に18mm～20mm）に対して、左右のセンサーが線の両端に位置するように配置すると、最も安定します。

6. 発展的なアイデア：さらに高度なロボットへ

基本のライントレーサーが完成したら、以下のような拡張に挑戦してみましょう。

  • PID制御の導入: 現在のプログラムはON/OFF制御ですが、PID制御（比例・積分・微分）を用いることで、より滑らかで高速な追従が可能になります。
  • 3センサー化・5センサー化: センサーを増やすことで、より複雑なコース（直角カーブや交差点）を正確に判別できます。
  • スピード切り替え: タクトスイッチを追加し、コースの難易度に応じて速度を変更できるようにします。
  • LCDディスプレイの搭載: 現在のセンサー値やモーター速度をリアルタイム表示し、デバッグを容易にします。
  • Bluetoothモジュール: スマートフォンからロボットを遠隔操作できるようにするのも面白いでしょう。

7. よくあるトラブルと解決法（FAQ）

製作中に直面しやすい問題とその対処法をまとめました。

  • モーターが全く動かない: バッテリー残量、配線の緩み、モータードライバの電源LEDを確認。特にGNDが共通接続されているか再確認してください。
  • モーターが一方向にしか回らない: IN1～IN4の接続が間違っているか、プログラムのピン設定が間違っています。
  • センサーが常に黒を検知する: 周囲の明るさ（太陽光や照明）の影響を受けています。センサーの感度調整を行い、可能であれば遮光板を取り付けましょう。
  • カーブで線を外してしまう: 速度を落とすか、旋回速度を上げてください。また、センサーの取り付け位置がロボットの中心から離れすぎている可能性があります。
  • Arduino IDEで書き込みエラーが出る: ボードの選択（Arduino Uno）とCOMポートが正しいか確認してください。USBケーブルは充電専用ではなく、データ通信対応のものを使用しましょう。
