Guía Definitiva: Cómo Construir un Robot Seguidor de Línea con Arduino Uno

¿Alguna vez has soñado con construir tu propio robot desde cero? El robot seguidor de línea con Arduino Uno es, sin duda, el proyecto perfecto para iniciarte en el fascinante mundo de la robótica. No solo aprenderás los fundamentos de la electrónica y la programación, sino que también tendrás en tus manos una máquina inteligente capaz de tomar decisiones autónomas. En esta guía completa, te llevaré de la mano paso a paso, desde la selección de materiales hasta la calibración final, para que puedas construir tu propio autómata sin frustraciones.

¿Qué es un Robot Seguidor de Línea y Cómo Funciona?

Un robot seguidor de línea es un vehículo autónomo diseñado para seguir una trayectoria marcada en el suelo, generalmente una línea negra sobre una superficie blanca (o viceversa). Su lógica de funcionamiento es sorprendentemente sencilla y se basa en un principio de retroalimentación constante.

El "cerebro" del sistema es el Arduino Uno, que procesa la información recibida de los sensores. Los "ojos" del robot son los sensores infrarrojos (IR), que detectan la diferencia de reflectancia entre la superficie clara y la línea oscura. Cuando el robot se desvía de la línea, el sensor detecta el cambio y envía una señal al Arduino, que a su vez ordena a los motores corregir la dirección.

La magia no está en la complejidad del hardware, sino en la lógica del algoritmo. Dominar este proyecto te dará las bases para crear máquinas mucho más complejas, como vehículos autónomos o brazos robóticos.

Lista de Materiales Esenciales para tu Proyecto

Antes de ensuciarte las manos, necesitas reunir todos los componentes. No te preocupes, la mayoría son económicos y fáciles de conseguir en tiendas online o locales de electrónica.

  • Placa Arduino Uno: El cerebro del robot. Puedes usar una original o una compatible (como la funduino).
  • Chasis para robot: Puedes comprar uno de acrílico o imprimirlo en 3D. También puedes improvisar con una placa de prototipos.
  • 2 Motores DC con caja reductora: Proporcionan el torque necesario para mover el robot a una velocidad controlable.
  • Puente H (L298N o L293D): Este módulo es vital, ya que permite controlar la dirección y velocidad de los motores desde el Arduino, que no puede suministrar suficiente corriente.
  • Sensor de línea (2 o 5 canales): Los módulos TCRT5000 son los más comunes. Te recomiendo empezar con uno de 2 canales para simplificar la lógica inicial.
  • Ruedas: Dos ruedas motrices y una rueda loca (bola) para el equilibrio.
  • Batería: Un pack de 4 pilas AA o una batería LiPo de 7.4V para alimentar los motores y el Arduino.
  • Cables jumper: Para realizar todas las conexiones.

Montaje Paso a Paso: El Hardware

El montaje físico es el primer gran reto. Sigue estos pasos con paciencia para evitar errores de conexión.

1. Ensamblaje del Chasis y Motores

Fija los motores DC al chasis con tornillos. Asegúrate de que las ruedas queden alineadas y puedan girar libremente. Instala la rueda loca en la parte frontal o trasera para mantener el equilibrio.

2. Colocación de los Sensores

Los sensores deben estar lo más cerca posible del suelo (entre 0.5 cm y 1.5 cm) para una lectura precisa. La distancia entre los dos sensores debe ser ligeramente menor que el ancho de la línea negra que seguirás.

3. Conexiones Eléctricas (El Cableado)

Esta es la parte más crítica. Una conexión incorrecta puede quemar tus componentes. Sigue esta tabla de referencia:

  • Motores al Puente H: Conecta los cables de cada motor a las salidas OUT1/OUT2 (Motor A) y OUT3/OUT4 (Motor B).
  • Puente H al Arduino: Conecta IN1, IN2, IN3, IN4 a los pines digitales 8, 9, 10 y 11 respectivamente. Conecta ENA y ENB a los pines PWM (5 y 6) para controlar la velocidad.
  • Sensores al Arduino: Conecta la salida digital del sensor izquierdo al pin digital 2 y la del derecho al pin digital 3. Alimenta los sensores con 5V y GND.
  • Alimentación: Conecta la batería al pin de alimentación del Puente H (12V o VIN). El Arduino puede alimentarse desde el Puente H (5V) o de forma independiente.

Programación del Arduino: El Corazón Lógico

Una vez que el hardware está listo, llega el momento de darle vida con el código. Abre el IDE de Arduino y copia este código base. Es un algoritmo de control proporcional extremadamente eficaz.

El código es simple: si el sensor izquierdo detecta la línea, el robot gira a la izquierda; si el derecho la detecta, gira a la derecha. Si ambos detectan la línea (o ninguno), avanza en línea recta.

// Definición de pines
int sensorIzq = 2;
int sensorDer = 3;
int motorA1 = 8;
int motorA2 = 9;
int motorB1 = 10;
int motorB2 = 11;

void setup() {
  pinMode(sensorIzq, INPUT);
  pinMode(sensorDer, INPUT);
  pinMode(motorA1, OUTPUT);
  pinMode(motorA2, OUTPUT);
  pinMode(motorB1, OUTPUT);
  pinMode(motorB2, OUTPUT);
}

void loop() {
  int lecturaIzq = digitalRead(sensorIzq);
  int lecturaDer = digitalRead(sensorDer);

  // Lógica de control (0 = línea negra detectada)
  if (lecturaIzq == LOW && lecturaDer == HIGH) {
    // Girar a la izquierda
    digitalWrite(motorA1, HIGH);
    digitalWrite(motorA2, LOW);
    digitalWrite(motorB1, LOW);
    digitalWrite(motorB2, HIGH);
  } 
  else if (lecturaIzq == HIGH && lecturaDer == LOW) {
    // Girar a la derecha
    digitalWrite(motorA1, LOW);
    digitalWrite(motorA2, HIGH);
    digitalWrite(motorB1, HIGH);
    digitalWrite(motorB2, LOW);
  }
  else {
    // Avanzar recto
    digitalWrite(motorA1, HIGH);
    digitalWrite(motorA2, LOW);
    digitalWrite(motorB1, HIGH);
    digitalWrite(motorB2, LOW);
  }
}
Si tu robot gira en sentido contrario al esperado, simplemente intercambia los cables de los motores o invierte las condiciones lógicas en el código.

Calibración y Resolución de Problemas Comunes

Es muy probable que tu robot no funcione perfectamente al primer intento. La calibración es un arte. Aquí tienes los problemas más frecuentes y sus soluciones.

  • El robot no se mueve: Verifica la alimentación. ¿Está cargada la batería? ¿El Puente H tiene voltaje?
  • Los motores vibran pero no giran: El voltaje es insuficiente. Aumenta la velocidad usando PWM (analogWrite) en los pines ENA y ENB.
  • El robot "zigzaguea" demasiado: Ajusta la velocidad base. Una velocidad demasiado alta provoca oscilaciones. Reduce el valor PWM a 150 o 200.
  • Los sensores no detectan la línea: Ajusta el potenciómetro del módulo TCRT5000 con un destornillador hasta que el LED del sensor se encienda sobre la línea negra y se apague sobre el fondo blanco.
  • El robot se sale de la pista en curvas cerradas: Aumenta la distancia entre los sensores o reduce la velocidad en las curvas.

Mejoras y Expansiones Futuras

¡Felicidades! Si has llegado hasta aquí, ya tienes un robot funcional. Pero esto es solo el comienzo. La belleza de Arduino es que puedes iterar y mejorar tu diseño indefinidamente.

  • Control PID: Implementa un controlador PID (Proporcional-Integral-Derivativo) para un seguimiento más suave y rápido. Necesitarás un sensor de 5 canales y un código más avanzado.
  • Pantalla LCD: Añade una pantalla para mostrar la velocidad, el estado de los sensores o el número de vueltas.
  • Control Bluetooth: Integra un módulo HC-05 para controlar el robot manualmente desde tu smartphone.
  • Modo "Espía": Añade una cámara o un sensor ultrasónico para evitar obstáculos mientras sigue la línea.

Construir un robot seguidor de línea con Arduino Uno no es solo un ejercicio técnico; es un viaje de aprendizaje que combina creatividad, lógica y resolución de problemas. Cada fallo es una lección, y cada ajuste exitoso es una victoria personal. No te desanimes si no funciona a la primera; la perseverancia es la cualidad más importante de un maker. Ahora, ¡enciende tu soldador, abre tu IDE y comienza a construir el futuro!
