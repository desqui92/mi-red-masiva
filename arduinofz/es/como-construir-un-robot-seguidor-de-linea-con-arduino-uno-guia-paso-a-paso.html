Cómo Construir un Robot Seguidor de Línea con Arduino Uno: Guía Paso a Paso

El mundo de la robótica educativa ha encontrado en Arduino su mejor aliado. Entre los proyectos más fascinantes y didácticos que existen, el robot seguidor de línea ocupa un lugar privilegiado. No solo es un proyecto ideal para principiantes, sino que también introduce conceptos fundamentales de electrónica, programación y control automático. En esta guía exhaustiva, te explicaremos cómo construir tu propio robot seguidor de línea utilizando un Arduino Uno, desde la selección de componentes hasta la calibración final del circuito.

¿Qué es un Robot Seguidor de Línea y Cómo Funciona?

Un robot seguidor de línea es un vehículo autónomo capaz de detectar y seguir una línea trazada en el suelo, generalmente de color negro sobre una superficie blanca (o viceversa). Su funcionamiento se basa en un principio simple pero poderoso: la reflectancia de la luz.

El sistema utiliza sensores infrarrojos (IR) que emiten luz y miden la cantidad de luz reflejada. La superficie blanca refleja la mayor parte de la luz infrarroja, mientras que la línea negra la absorbe. Esta diferencia en la reflectancia permite al microcontrolador (el Arduino Uno) tomar decisiones en tiempo real para corregir la trayectoria del robot.

💡 Dato clave: El cerebro del robot es el Arduino Uno, pero sus "ojos" son los sensores IR y sus "músculos" son los motores DC. La interacción entre estos tres elementos define la inteligencia del sistema.

Materiales y Componentes Necesarios

Antes de comenzar, es crucial reunir todos los componentes. Aquí tienes la lista completa para construir tu robot:

Componentes Electrónicos

  • 1x Placa Arduino Uno (o cualquier clon compatible)
  • 1x Módulo Puente H L298N (para controlar los motores)
  • 2x Motores DC con caja reductora (idealmente de 3 a 6 voltios)
  • 2x Ruedas (compatibles con los ejes de los motores)
  • 1x Rueda loca (para el punto de apoyo trasero o delantero)
  • 2x Sensores infrarrojos TCRT5000 (o un módulo seguidor de línea con 2 o 5 sensores)
  • 1x Portapilas para 4 pilas AA (6V) o una batería LiPo de 7.4V
  • Cables jumper (macho-macho y macho-hembra)

Estructura y Herramientas

  • Chasis de acrílico o impresión 3D (puedes usar una base de plástico rígido)
  • Destornilladores de precisión
  • Estaño y cautín (si decides soldar las conexiones)
  • Cinta aislante o bridas para fijar cables

Paso 1: Ensamblaje del Chasis y los Motores

El primer paso físico es montar la estructura. Si compraste un kit, sigue las instrucciones del fabricante. Si construyes tu propio chasis, asegúrate de que los motores queden firmemente sujetos y que las ruedas giren libremente.

Consejo profesional: Coloca la rueda loca en la parte delantera si los motores van atrás, o viceversa. Esto asegura un equilibrio estable y evita que el robot se incline hacia adelante o hacia atrás durante el movimiento.

Paso 2: Conexión del Puente H L298N

El módulo L298N actúa como un intermediario entre el Arduino y los motores. El Arduino no puede suministrar suficiente corriente para mover los motores directamente, por lo que el puente H se encarga de proporcionar la energía necesaria.

Sigue este esquema de conexión:

  • Conexión de alimentación: Conecta el pin 12V del L298N al positivo de la batería y el pin GND al negativo.
  • Alimentación lógica: El pin 5V del L298N puede alimentar al Arduino (si usas la misma fuente) o puedes usar el pin 5V del Arduino para alimentar la lógica del L298N.
  • Motores: Conecta el Motor A a los terminales OUT1 y OUT2. Conecta el Motor B a los terminales OUT3 y OUT4.
  • Control desde Arduino:
    • IN1 → Pin digital 5 del Arduino
    • IN2 → Pin digital 6 del Arduino
    • IN3 → Pin digital 10 del Arduino
    • IN4 → Pin digital 11 del Arduino

⚠️ Advertencia: Nunca conectes los motores directamente a los pines del Arduino. Podrías dañar la placa de forma irreversible. El puente H es obligatorio.

Paso 3: Instalación de los Sensores Infrarrojos

Los sensores TCRT5000 son la parte más sensible del robot. Deben colocarse en la parte frontal, a una distancia de 1 a 2 centímetros del suelo. La separación entre ambos sensores debe ser ligeramente mayor que el ancho de la línea que vas a seguir.

Conexión de los sensores:

  • Sensor Izquierdo:
    • VCC → 5V del Arduino
    • GND → GND del Arduino
    • OUT → Pin digital 2 del Arduino
  • Sensor Derecho:
    • VCC → 5V del Arduino
    • GND → GND del Arduino
    • OUT → Pin digital 3 del Arduino

Ajusta el potenciómetro de cada sensor (si lo tiene) para calibrar la sensibilidad. Gíralo lentamente hasta que el LED indicador del sensor se encienda cuando esté sobre una superficie blanca y se apague sobre la línea negra.

Paso 4: Programación del Arduino Uno

Ahora viene la parte más emocionante: darle vida al robot mediante código. Abre el IDE de Arduino y escribe el siguiente programa. Este código implementa una lógica de control proporcional básica que permite al robot tomar curvas suaves.

// Definición de pines
const int sensorIzq = 2;
const int sensorDer = 3;

const int motorA1 = 5;
const int motorA2 = 6;
const int motorB1 = 10;
const int motorB2 = 11;

// Velocidades base
int velocidadBase = 180;
int velocidadGiro = 120;

void setup() {
  pinMode(sensorIzq, INPUT);
  pinMode(sensorDer, INPUT);
  
  pinMode(motorA1, OUTPUT);
  pinMode(motorA2, OUTPUT);
  pinMode(motorB1, OUTPUT);
  pinMode(motorB2, OUTPUT);
  
  // Inicializar motores apagados
  digitalWrite(motorA1, LOW);
  digitalWrite(motorA2, LOW);
  digitalWrite(motorB1, LOW);
  digitalWrite(motorB2, LOW);
}

void loop() {
  // Leer sensores (LOW = sobre línea negra, HIGH = sobre blanco)
  int estadoIzq = digitalRead(sensorIzq);
  int estadoDer = digitalRead(sensorDer);
  
  // Lógica de control
  if (estadoIzq == LOW && estadoDer == HIGH) {
    // Robot se desvía a la izquierda, girar a la derecha
    girarDerecha();
  } 
  else if (estadoIzq == HIGH && estadoDer == LOW) {
    // Robot se desvía a la derecha, girar a la izquierda
    girarIzquierda();
  } 
  else {
    // Ambos sensores sobre blanco o sobre negro: avanzar recto
    avanzarRecto();
  }
}

void avanzarRecto() {
  analogWrite(motorA1, velocidadBase);
  digitalWrite(motorA2, LOW);
  analogWrite(motorB1, velocidadBase);
  digitalWrite(motorB2, LOW);
}

void girarDerecha() {
  // Motor izquierdo gira más rápido, motor derecho más lento
  analogWrite(motorA1, velocidadBase);
  digitalWrite(motorA2, LOW);
  analogWrite(motorB1, velocidadGiro);
  digitalWrite(motorB2, LOW);
}

void girarIzquierda() {
  // Motor derecho gira más rápido, motor izquierdo más lento
  analogWrite(motorA1, velocidadGiro);
  digitalWrite(motorA2, LOW);
  analogWrite(motorB1, velocidadBase);
  digitalWrite(motorB2, LOW);
}

Paso 5: Calibración y Ajustes Finos

Una vez cargado el código, es momento de probar el robot. Colócalo sobre una pista de prueba (cinta aislante negra sobre cartulina blanca funciona perfectamente). Observa su comportamiento y realiza los siguientes ajustes:

  • Velocidad excesiva: Si el robot pierde la línea en las curvas, reduce el valor de velocidadBase (prueba con 140 o 150).
  • Giros bruscos: Si el robot zigzaguea mucho, aumenta el valor de velocidadGiro para que se acerque a la velocidad base.
  • Sensibilidad: Si los sensores no detectan bien la línea, ajusta los potenciómetros nuevamente y verifica la distancia al suelo.

Mejoras Avanzadas para tu Robot

Una vez que el robot básico funcione correctamente, puedes desafiarte a ti mismo implementando estas mejoras:

1. Control PID (Proporcional-Integral-Derivativo)

En lugar de usar solo dos sensores, puedes usar un array de 5 o 8 sensores y aplicar un algoritmo PID. Esto permite que el robot siga la línea de forma mucho más suave y a mayor velocidad, calculando la posición exacta del robot respecto a la línea.

2. Gestión de Cruces y Bifurcaciones

Puedes programar el robot para que tome decisiones en intersecciones. Por ejemplo, contar el número de cruces o elegir siempre el camino de la derecha. Esto requiere lógica adicional y posiblemente un sensor extra.

3. Memoria de Recorrido

Con la adición de una memoria EEPROM, el robot puede aprender un recorrido y luego reproducirlo sin necesidad de los sensores, simulando un comportamiento de "memoria muscular".

4. Velocidad Adaptativa

Usa un potenciómetro externo para ajustar la velocidad en tiempo real, o implementa un sistema que acelere en rectas y frene en curvas basándose en la lectura de los sensores.

Problemas Comunes y Soluciones

Es normal encontrar dificultades en el primer intento. Aquí tienes una tabla con los problemas más frecuentes:

  • El robot no se mueve: Verifica que la batería esté cargada y que el puente H tenga alimentación. Comprueba que los pines IN1-IN4 estén correctamente conectados.
  • Un solo motor funciona: Revisa las conexiones del motor que no funciona. Prueba intercambiando los cables del motor en el puente H para descartar un fallo del motor.
  • El robot vibra sin avanzar: Esto indica que los motores reciben señal pero no tienen suficiente torque. Asegúrate de que las ruedas estén acopladas firmemente al eje y que no haya fricción excesiva.
  • Los sensores no responden: Mide el voltaje de salida del sensor con un multímetro. Debería estar cerca de 0V sobre negro y cerca de 5V sobre blanco.
  • El robot se sale de la línea constantemente: Reduce la velocidad y ajusta la distancia de los sensores al suelo. A veces, un pequeño cambio de 1mm en la altura hace una gran diferencia.

Conclusión

A lo largo de este tutorial, has aprendido a integrar hardware y software, a comprender conceptos de control automático y a resolver problemas de forma metódica.

Este proyecto te proporciona una base sólida sobre la cual puedes construir proyectos mucho más complejos, como robots exploradores, brazos robóticos o incluso vehículos autónomos a mayor escala. La lógica de toma de decisiones que has implementado es la misma que utilizan los robots industriales para seguir rutas en almacenes o los coches autónomos para mantenerse en su carril.

No te desanimes si tu primer prototipo no funciona perfectamente a la primera. La experimentación y el ajuste continuo son parte esencial del aprendizaje. Cada vez que modifiques un parámetro y observes el resultado, estarás un paso más cerca de dominar el arte de la robótica. ¡Anímate a experimentar, modifica el código, añade nuevos sensores y crea tu propia versión mejorada!
