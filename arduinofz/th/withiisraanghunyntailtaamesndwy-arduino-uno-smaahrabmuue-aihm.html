วิธีสร้างหุ่นยนต์ไล่ตามเส้นด้วย Arduino Uno สำหรับมือใหม่

การสร้างหุ่นยนต์เป็นหนึ่งในโปรเจกต์ยอดนิยมสำหรับผู้ที่เริ่มต้นเรียนรู้ระบบสมองกลฝังตัว และหนึ่งในโปรเจกต์คลาสสิกที่ทุกคนควรลองคือ หุ่นยนต์ไล่ตามเส้น (Line Follower Robot) ซึ่งเป็นพื้นฐานสำคัญของระบบอัตโนมัติในโรงงานอุตสาหกรรม ไม่ว่าจะเป็นรถขนส่งอัตโนมัติในคลังสินค้า หรือหุ่นยนต์ทำความสะอาดพื้น บทความนี้จะพาคุณไปทีละขั้นตอน ตั้งแต่การเลือกอุปกรณ์ การประกอบวงจร ไปจนถึงการเขียนโค้ดด้วย Arduino Uno เพื่อให้หุ่นยนต์ของคุณวิ่งไปตามเส้นดำบนพื้นสีขาวได้อย่างราบรื่น

หลักการทำงานของหุ่นยนต์ไล่ตามเส้น

หัวใจของหุ่นยนต์ชนิดนี้คือ เซนเซอร์ตรวจจับแสงสะท้อน โดยทั่วไปจะใช้เซนเซอร์อินฟราเรด (IR) ประกอบด้วยหลอด LED ที่ปล่อยแสงอินฟราเรดออกมา และโฟโต้ทรานซิสเตอร์ที่รับแสงสะท้อนกลับ หลักการคือ:

  • พื้นสีขาว: สะท้อนแสงอินฟราเรดกลับมาได้ดี ทำให้เซนเซอร์อ่านค่าได้สูง (HIGH)
  • เส้นสีดำ: ดูดซับแสงอินฟราเรดเกือบทั้งหมด ทำให้เซนเซอร์อ่านค่าได้ต่ำ (LOW)

เมื่อเซนเซอร์ทั้งสองข้างตรวจพบค่าที่ต่างกัน (ข้างหนึ่งอยู่บนเส้น อีกข้างอยู่นอกเส้น) ตัวควบคุม (Arduino) จะสั่งให้มอเตอร์แต่ละข้างหมุนด้วยความเร็วต่างกัน เพื่อเลี้ยวกลับเข้าหาเส้นเสมอ เปรียบเสมือนหุ่นยนต์กำลัง "หนี" ออกจากเส้นแล้วรีบกลับเข้ามาใหม่ตลอดเวลา

หมายเหตุ: หุ่นยนต์ไล่ตามเส้นมี 2 ประเภทหลัก คือ แบบดิจิทัล (อ่านค่าได้แค่ 0/1) และแบบแอนะล็อก (อ่านค่าความเข้มแสงได้ละเอียดกว่า) สำหรับบทความนี้ เราจะใช้แบบดิจิทัล 5 ช่อง ซึ่งเป็นที่นิยมและหาซื้อได้ง่าย

อุปกรณ์ที่ต้องเตรียม

ก่อนเริ่มลงมือประกอบ ขอแนะนำให้เตรียมอุปกรณ์ดังต่อไปนี้ให้ครบถ้วน เพื่อความราบรื่นในการทำงาน

  • บอร์ด Arduino Uno (1 ชุด) พร้อมสาย USB สำหรับอัปโหลดโค้ด
  • เซนเซอร์ไลน์ติดตาม 5 ช่อง (TCRT5000) หรือแบบ 2 ช่องก็ได้ แต่ 5 ช่องจะทำงานได้ลื่นไหลกว่า
  • โมดูลขับมอเตอร์ L298N หรือ L293D (ใช้ควบคุมทิศทางและความเร็วมอเตอร์)
  • แชสซีหุ่นยนต์ 2 ล้อ พร้อมมอเตอร์ DC เกียร์ทด (พร้อมล้อและล้อเลื่อนด้านหลัง)
  • แบตเตอรี่ 6-12V (ถ่าน 18650 จำนวน 2 ก้อน หรือแบตเตอรี่ 9V) พร้อมขั้วต่อ
  • สายไฟจัมเปอร์ (ตัวผู้-ตัวเมีย และตัวผู้-ตัวผู้) จำนวนพอประมาณ
  • ไขควงและเทปสองหน้า สำหรับติดตั้งอุปกรณ์เข้ากับแชสซี

ขั้นตอนการต่อวงจร (Wiring Diagram)

การต่อวงจรเป็นขั้นตอนที่ต้องใช้ความระมัดระวัง หากต่อผิดอาจทำให้เซนเซอร์หรือบอร์ดเสียหายได้ ให้ทำตามแผนผังด้านล่างนี้ทีละจุด

1. การเชื่อมต่อเซนเซอร์กับ Arduino

โมดูลเซนเซอร์ 5 ช่อง จะมีขาเอาต์พุต 5 ขา (OUT1 ถึง OUT5) และขาไฟเลี้ยง (VCC, GND) ทำการเชื่อมต่อดังนี้:

  • ขา VCC ของเซนเซอร์ -> ขา 5V ของ Arduino
  • ขา GND ของเซนเซอร์ -> ขา GND ของ Arduino
  • ขา OUT1 -> ขาดิจิทัล D2
  • ขา OUT2 -> ขาดิจิทัล D3
  • ขา OUT3 -> ขาดิจิทัล D4
  • ขา OUT4 -> ขาดิจิทัล D5
  • ขา OUT5 -> ขาดิจิทัล D6

2. การเชื่อมต่อโมดูลขับมอเตอร์ L298N

โมดูลนี้ทำหน้าที่เป็นสะพานเชื่อมระหว่าง Arduino กับมอเตอร์ โดยมีขาหลักๆ ดังนี้:

  • ขา 12V (หรือ VMS) -> ต่อกับขั้วบวกของแบตเตอรี่ (หากใช้แบต 12V) หรือต่อกับ 5V ของ Arduino หากใช้แบต 7.4V ขึ้นไป
  • ขา GND -> ต่อร่วมกับ GND ของ Arduino และขั้วลบของแบตเตอรี่ (ต้องต่อร่วมกันทั้งหมด)
  • ขา ENA (Enable A) -> ขา PWM ของ Arduino ขา D9 (ใช้ควบคุมความเร็วมอเตอร์ซ้าย)
  • ขา IN1 -> ขา D7 ของ Arduino
  • ขา IN2 -> ขา D8 ของ Arduino
  • ขา IN3 -> ขา D10 ของ Arduino
  • ขา IN4 -> ขา D11 ของ Arduino
  • ขา ENB (Enable B) -> ขา PWM ของ Arduino ขา D12 (ใช้ควบคุมความเร็วมอเตอร์ขวา)
  • ขา OUT1/OUT2 -> ต่อกับมอเตอร์ซ้าย, OUT3/OUT4 -> ต่อกับมอเตอร์ขวา
ข้อควรระวัง: หากใช้แบตเตอรี่ 9V ทั่วไป กระแสอาจไม่เพียงพอต่อการขับเคลื่อนมอเตอร์ 2 ตัวพร้อมกัน แนะนำให้ใช้แบตเตอรี่ลิเธียม 7.4V ขึ้นไป เพื่อประสิทธิภาพที่ดีที่สุด

การเขียนโค้ดควบคุมด้วย Arduino IDE

เมื่อต่อวงจรเสร็จเรียบร้อย ต่อไปคือการเขียนโปรแกรม โค้ดด้านล่างนี้เป็นเวอร์ชันสมบูรณ์สำหรับเซนเซอร์ 5 ช่อง พร้อมคำอธิบายภายในโค้ด

โครงสร้างโค้ดหลัก

เราจะใช้หลักการอ่านค่าจากเซนเซอร์ทั้ง 5 ตัว แล้วแปลงเป็น "ตำแหน่งของเส้น" โดยใช้ตัวแปร error จากนั้นจึงคำนวณความเร็วมอเตอร์ซ้าย-ขวา ด้วยเทคนิคที่เรียกว่า P (Proportional) Controller แบบง่ายๆ

อัปโหลดโค้ดและทดสอบการทำงาน

หลังจากเขียนโค้ดเสร็จ ให้ทำตามขั้นตอนต่อไปนี้:

  1. เชื่อมต่อ Arduino Uno เข้ากับคอมพิวเตอร์ด้วยสาย USB
  2. เปิดโปรแกรม Arduino IDE เลือกบอร์ดเป็น "Arduino Uno" และเลือกพอร์ตที่ถูกต้อง
  3. กดปุ่ม Upload เพื่ออัปโหลดโค้ด
  4. วางหุ่นยนต์ลงบนสนามทดสอบที่มีเส้นดำบนพื้นสีขาว (เส้นควรมีความหนาประมาณ 2-3 เซนติเมตร)
  5. เปิดสวิตช์จ่ายไฟให้มอเตอร์ แล้ววางหุ่นยนต์ให้เซนเซอร์กลางอยู่เหนือเส้น

หากทุกอย่างถูกต้อง หุ่นยนต์จะเริ่มเคลื่อนที่ไปข้างหน้าและเลี้ยวตามเส้นโดยอัตโนมัติ หากหุ่นยนต์วิ่งออกนอกเส้น ให้ตรวจสอบขั้วมอเตอร์ (สลับสาย IN1/IN2 หรือ IN3/IN4) เพื่อกลับทิศทางการเลี้ยว

การปรับแต่งค่าต่างๆ ให้หุ่นยนต์วิ่งลื่นไหล

หุ่นยนต์ที่สร้างเสร็จอาจยังวิ่งไม่ดีในครั้งแรก ต้องอาศัยการปรับแต่งพารามิเตอร์เล็กน้อย

  • ความเร็วฐาน (baseSpeed): หากเร็วเกินไป หุ่นยนต์จะเหวี่ยงออกนอกเส้นในโค้ง ให้ลดค่าลงประมาณ 150-180
  • ค่า Kp (Proportional gain): ค่านี้ควบคุมความไวในการเลี้ยว หากหุ่นยนต์เลี้ยวช้าเกินไป ให้เพิ่มค่า Kp แต่ถ้าสั่นหรือแกว่ง ให้ลดค่าลง
  • ระยะห่างของเซนเซอร์กับพื้น: เซนเซอร์ควรอยู่สูงจากพื้นประมาณ 1-1.5 เซนติเมตร หากสูงหรือต่ำเกินไปจะทำให้ค่าที่อ่านได้ไม่ชัดเจน
  • ความหนาของเส้น: เส้นที่หนาเกินไปอาจทำให้เซนเซอร์กลางอ่านค่าผิดพลาดได้ แนะนำให้ใช้เส้นขนาด 1.5-2 เท่าของระยะห่างเซนเซอร์

แนวคิดการพัฒนาต่อยอด

เมื่อคุณสร้างหุ่นยนต์ไล่ตามเส้นได้สำเร็จแล้ว นี่คือไอเดียเพิ่มเติมเพื่อพัฒนาทักษะของคุณ:

  • เพิ่มเซนเซอร์วัดระยะอัลตราโซนิก เพื่อให้หุ่นยนต์หยุดเมื่อเจอสิ่งกีดขวางบนเส้น
  • แสดงผลบนจอ LCD เพื่อแสดงความเร็วหรือจำนวนรอบที่วิ่งได้
  • ควบคุมด้วยรีโมทบลูทูธ เพื่อสลับโหมดระหว่างไล่เส้นและควบคุมด้วยมือ
  • ใช้ PID Controller แบบเต็มรูปแบบ (เพิ่มค่า Ki และ Kd) เพื่อให้การเลี้ยวนุ่มนวลและแม่นยำยิ่งขึ้น รองรับโค้งหักศอกได้ดี

สรุป

การสร้างหุ่นยนต์ไล่ตามเส้นด้วย Arduino Uno เป็นโปรเจกต์ที่ท้าทายแต่ให้ความรู้ครบถ้วน ทั้งด้านฮาร์ดแวร์ (การต่อวงจร) ซอฟต์แวร์ (การเขียนโค้ดควบคุม) และหลักการควบคุมอัตโนมัติพื้นฐาน เมื่อคุณเข้าใจหลักการทำงานของเซนเซอร์และการควบคุมมอเตอร์แล้ว คุณสามารถนำความรู้ไปประยุกต์ใช้กับโปรเจกต์หุ่นยนต์ประเภทอื่นๆ ได้อีกมากมาย อย่าลืมทดลองปรับแต่งค่าต่างๆ ด้วยตัวเอง เพื่อให้เห็นถึงผลลัพธ์ที่เปลี่ยนแปลงไป และที่สำคัญที่สุดคือ ขอให้สนุกกับการสร้างสรรค์ผลงานชิ้นแรกของคุณ
