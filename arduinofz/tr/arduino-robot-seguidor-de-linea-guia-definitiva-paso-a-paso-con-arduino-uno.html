Arduino Robot Seguidor de Línea: Guía Definitiva Paso a Paso con Arduino Uno

El robot seguidor de línea es, sin duda, el proyecto más emblemático y gratificante para todo aquel que se inicia en el mundo de la robótica y la electrónica. No solo es un desafío técnico perfecto para aprender, sino que también es la base conceptual de sistemas mucho más complejos, como los vehículos autónomos o los robots de almacén. En esta guía definitiva, te enseñaremos a construir tu propio robot seguidor de línea con Arduino Uno, desde los componentes necesarios hasta el código final, explicando cada paso para que entiendas no solo el "cómo", sino también el "por qué".

¿Qué es un Robot Seguidor de Línea y Cómo Funciona?

Un robot seguidor de línea es un vehículo autónomo capaz de detectar y seguir una línea trazada en el suelo (generalmente negra sobre fondo blanco, o viceversa). Su funcionamiento se basa en un principio de retroalimentación (feedback):

  • Percepción: Utiliza sensores infrarrojos (IR) para "ver" la superficie. Estos sensores emiten luz infrarroja y miden la cantidad de luz que se refleja. Una superficie blanca refleja casi toda la luz, mientras que una superficie negra la absorbe casi por completo.
  • Procesamiento: El Arduino Uno lee las señales de los sensores (analógicas o digitales) y decide qué hacer. Si el sensor izquierdo detecta la línea, significa que el robot se está desviando hacia la derecha, por lo que debe corregir su rumbo girando a la izquierda.
  • Acción: El microcontrolador envía órdenes a los drivers de motor (como el L298N) para que ajusten la velocidad de los motores DC. De esta manera, el robot corrige su trayectoria constantemente, manteniéndose sobre la línea.

Lista de Componentes Necesarios para tu Arduino Robot

Antes de comenzar, es crucial tener todos los materiales a la mano. Para este proyecto necesitarás:

  • Placa Arduino Uno (el cerebro del robot).
  • Chasis para robot (puede ser de acrílico, impresión 3D o incluso una base de cartón resistente).
  • 2 Motores DC con caja reductora (y sus ruedas).
  • 1 Rueda loca (para dar estabilidad al frente o atrás).
  • Puente H (Driver de motor) L298N o el más moderno L293D. Este componente es vital para controlar la dirección y velocidad de los motores.
  • Módulo sensor infrarrojo TCRT5000 (idealmente un módulo de 2 o 5 sensores). Para una guía básica, con 2 es suficiente, pero con 3 o 5 el seguimiento es más suave.
  • Batería: Una power bank de 5V o un pack de baterías recargables (6V o 7.4V) para alimentar los motores y la placa.
  • Cables jumper macho-macho y macho-hembra.
  • Destornillador y cinta doble cara.

Paso 1: Ensamblaje Físico del Chasis

El primer paso es puramente mecánico. Debes montar los motores DC en el chasis y fijar las ruedas. Asegúrate de que los motores estén alineados correctamente para que el robot avance en línea recta cuando ambos giren a la misma velocidad. Coloca la rueda loca en el extremo opuesto para crear un trípode de soporte estable.

  • Consejo profesional: Ajusta los tornillos firmemente, pero sin pasarte, para no dañar el chasis.
  • Deja espacio suficiente sobre la plataforma para colocar el Arduino Uno y el puente H.

Paso 2: Montaje de los Sensores de Línea

La altura de los sensores IR respecto al suelo es crítica. Si están demasiado altos, captarán reflejos difusos y fallarán; si están demasiado bajos, pueden rozar el suelo. La distancia óptima suele estar entre 0.5 cm y 1.5 cm.

Coloca el módulo sensor en la parte delantera del chasis, apuntando hacia el suelo. Si usas un módulo de 2 sensores, sepáralos unos 5-7 cm entre sí para que uno quede a cada lado de la línea. Si usas uno de 5, el central debe estar justo sobre la línea.

Paso 3: Conexiones Eléctricas (El Cableado)

Aquí es donde muchos principiantes se pierden. Sigue este esquema de conexión para el driver L298N y el Arduino Uno:

Conexión del Puente H (L298N):

  • Motor A y Motor B: Conecta los cables de los motores DC a los terminales de tornillo del L298N (Out1, Out2 para Motor A; Out3, Out4 para Motor B).
  • 12V (Alimentación): Conecta el positivo de la batería de motores (7.4V recomendado) aquí.
  • GND (Tierra): Conecta el negativo de la batería. IMPORTANTE: También debes conectar este GND al pin GND del Arduino Uno para que compartan la misma referencia de voltaje.
  • 5V (Salida): Este pin puede alimentar el Arduino si tu batería es de más de 7V. Si usas una power bank USB, no lo uses.
  • ENA y ENB: Conéctalos a los pines PWM del Arduino (Ej: Pin 5 y Pin 6). Controlan la velocidad.
  • IN1, IN2, IN3, IN4: Conéctalos a pines digitales (Ej: Pines 7, 8, 9, 10). Controlan la dirección de giro.

Conexión del Sensor TCRT5000:

  • VCC: Al pin 5V del Arduino.
  • GND: Al pin GND del Arduino.
  • OUT (Sensor Izq): Al pin digital 2 del Arduino.
  • OUT (Sensor Der): Al pin digital 3 del Arduino.
ADVERTENCIA: Verifica dos veces las conexiones antes de encender. Una conexión inversa en el L298N puede dañar tanto el driver como el Arduino.

Paso 4: Lógica de Programación y Código Arduino

La lógica es sencilla: si el sensor izquierdo detecta la línea (negro), el motor derecho debe girar más rápido (para volver a la izquierda). Si el sensor derecho detecta la línea, el motor izquierdo acelera. Si ambos detectan la línea (cruce) o ninguno (pista perdida), el robot avanza recto.

Aquí tienes el código completo y comentado para tu robot seguidor de línea con Arduino Uno:

// Definición de pines para los motores (L298N)
const int motorA1 = 7;
const int motorA2 = 8;
const int motorB1 = 9;
const int motorB2 = 10;
const int velocidadA = 5; // PWM Motor A
const int velocidadB = 6; // PWM Motor B

// Definición de pines para sensores IR
const int sensorIzq = 2;
const int sensorDer = 3;

// Variables de estado de los sensores
int valorIzq = 0;
int valorDer = 0;

// Velocidad base del robot (0-255)
const int velBase = 150;
// Velocidad de corrección (giro)
const int velGiro = 200;

void setup() {
  // Configurar pines de motor como salidas
  pinMode(motorA1, OUTPUT);
  pinMode(motorA2, OUTPUT);
  pinMode(motorB1, OUTPUT);
  pinMode(motorB2, OUTPUT);
  
  // Configurar pines de sensor como entradas
  pinMode(sensorIzq, INPUT);
  pinMode(sensorDer, INPUT);
  
  // Iniciar comunicación serial para depuración (opcional)
  Serial.begin(9600);
}

void loop() {
  // Leer los sensores (0 = línea negra detectada, 1 = superficie blanca)
  valorIzq = digitalRead(sensorIzq);
  valorDer = digitalRead(sensorDer);

  // Lógica de control
  if (valorIzq == LOW && valorDer == HIGH) {
    // Robot se desvía a la derecha: girar a la izquierda
    // Motor izquierdo frena, motor derecho avanza
    digitalWrite(motorA1, LOW);
    digitalWrite(motorA2, HIGH);
    digitalWrite(motorB1, HIGH);
    digitalWrite(motorB2, LOW);
    analogWrite(velocidadA, velGiro);
    analogWrite(velocidadB, velGiro);
  } 
  else if (valorIzq == HIGH && valorDer == LOW) {
    // Robot se desvía a la izquierda: girar a la derecha
    digitalWrite(motorA1, HIGH);
    digitalWrite(motorA2, LOW);
    digitalWrite(motorB1, LOW);
    digitalWrite(motorB2, HIGH);
    analogWrite(velocidadA, velGiro);
    analogWrite(velocidadB, velGiro);
  } 
  else {
    // Ambos sensores en blanco (recto) o ambos en negro (cruce)
    // Avanzar en línea recta
    digitalWrite(motorA1, HIGH);
    digitalWrite(motorA2, LOW);
    digitalWrite(motorB1, HIGH);
    digitalWrite(motorB2, LOW);
    analogWrite(velocidadA, velBase);
    analogWrite(velocidadB, velBase);
  }
}

Paso 5: Calibración de Sensores

La calibración es el secreto para un robot estable. Si tu módulo TCRT5000 tiene un potenciómetro (un tornillito pequeño), úsalo para ajustar la sensibilidad.

  • Coloca el sensor sobre la superficie blanca y gira el potenciómetro hasta que el LED indicador del módulo se apague (o encienda, según el modelo).
  • Coloca el sensor sobre la línea negra y verifica que el estado del LED cambie.
  • Repite el proceso hasta que la detección sea nítida y sin parpadeos.

Problemas Comunes y Soluciones

Aunque el montaje sea correcto, pueden surgir problemas. Aquí te dejamos los más habituales y cómo resolverlos:

  • El robot vibra o no avanza: Revisa la alimentación. Si la batería está baja o el voltaje es insuficiente, los motores no tendrán fuerza. Asegúrate de que el GND del Arduino y del L298N estén conectados.
  • El robot se sale de la línea en las curvas: Reduce la velocidad base (velBase) en el código. Un robot más lento tiene más tiempo para reaccionar. También puedes aumentar la velocidad de giro (velGiro).
  • Los sensores no detectan bien: Ajusta la altura del sensor o la calibración del potenciómetro. La luz ambiental intensa puede interferir; intenta aislar los sensores con cinta aislante negra.
  • El robot avanza hacia atrás: Simplemente invierte los cables de los motores en el conector del L298N, o cambia los estados HIGH/LOW en el código.

Mejoras y Expansión del Proyecto

Una vez que tu robot seguidor de línea con Arduino Uno funcione perfectamente, el siguiente paso es desafiarte a ti mismo. Aquí tienes algunas ideas para llevarlo al siguiente nivel:

  • Control PID (Proporcional-Integral-Derivativo): En lugar de usar una lógica binaria (todo o nada), usa un sensor de 5 canales y un algoritmo PID. Esto permite que el robot gire con suavidad y a altas velocidades sin perder la línea. Es el estándar en competiciones de robótica.
  • Pantalla LCD: Conecta una pantalla LCD para mostrar la velocidad actual, el estado de los sensores o el tiempo de recorrido.
  • Bluetooth: Añade un módulo HC-05 para controlar el robot de forma inalámbrica o para ajustar la velocidad en tiempo real desde tu móvil.
  • Memorización de rutas: Programa el robot para que aprenda un circuito en la primera pasada y lo repita a máxima velocidad en la segunda.
