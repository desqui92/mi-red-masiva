Comment construire un robot suiveur de ligne avec Arduino Uno : Le guide complet pour débutants

Construire un robot suiveur de ligne est sans doute l'un des projets les plus gratifiants et les plus pédagogiques dans le monde de la robotique DIY. Que vous soyez un étudiant en électronique, un hobbyiste curieux ou un enseignant cherchant un projet pratique, ce tutoriel est fait pour vous. Grâce à la simplicité de la carte Arduino Uno et à quelques composants abordables, vous allez pouvoir assembler, câbler et programmer votre propre machine capable de suivre une trajectoire noire sur un fond blanc (ou l'inverse). Cet article vous guidera pas à pas, du choix des matériaux à la mise en service, en passant par la logique de programmation.

1. Pourquoi un robot suiveur de ligne ? Les fondamentaux

Avant de vous lancer dans le câblage, il est essentiel de comprendre le principe de fonctionnement. Un robot suiveur de ligne utilise des capteurs de proximité infrarouge (IR) pour détecter la réflectance de la surface. Une surface blanche réfléchit la lumière, tandis qu'une surface noire l'absorbe. En lisant ces variations, la carte Arduino peut prendre des décisions pour actionner les moteurs et corriger la trajectoire du robot.

Ce projet est idéal pour apprendre :

  • La logique de contrôle (boucles conditionnelles et capteurs).
  • Les bases de l'électronique (pont en H, résistances, alimentation).
  • La programmation embarquée (lecture analogique et numérique).

2. La liste complète du matériel nécessaire

Pour ce tutoriel, nous allons utiliser une approche modulaire. Voici la liste exhaustive des composants dont vous aurez besoin :

  • 1x Carte Arduino Uno (ou un clone compatible).
  • 1x Module pont en H L298N (pour contrôler deux moteurs à courant continu).
  • 2x Moteurs à courant continu avec réducteurs (idéalement 3V à 6V) et leurs roues.
  • 1x Module capteur suiveur de ligne (souvent vendu comme "TCRT5000" ou "module 5 canaux"). Pour un début, un module à 2 ou 3 capteurs suffit.
  • 1x Roue folle (ou bille de maintien) pour l'équilibre à l'avant.
  • 1x Support de piles pour 4 piles AA (6V) ou une batterie LiPo 7.4V.
  • Des câbles Dupont (mâle-mâle et mâle-femelle).
  • Un châssis (en acrylique, impression 3D ou même en carton rigide).
  • Des serre-câbles ou du ruban adhésif double face pour fixer les composants.
Astuce de pro : Si vous achetez un "kit robot suiveur de ligne", il contient souvent tous ces éléments. Vérifiez simplement que le capteur est bien un module TCRT5000 pour une meilleure précision.

3. Le câblage : Connecter les composants à l'Arduino

Le câblage est une étape critique. Une erreur de connexion peut endommager votre carte. Suivez ce schéma de câblage méticuleusement.

Connexion du pont en H L298N :

  • Broche 12V du L298N -> +6V de la batterie (ou le fil positif).
  • Broche GND du L298N -> GND de la batterie ET broche GND de l'Arduino.
  • Broche 5V du L298N -> Broche 5V de l'Arduino (pour alimenter les capteurs).
  • Broches IN1, IN2, IN3, IN4 -> Broches numériques D8, D9, D10, D11 de l'Arduino.
  • Broches ENA et ENB -> Broches D5 et D6 (pour le contrôle de vitesse PWM).

Connexion des moteurs :

  • Moteur gauche -> Borniers OUT1 et OUT2.
  • Moteur droit -> Borniers OUT3 et OUT4.

Connexion du capteur (exemple avec 2 capteurs) :

  • VCC du capteur -> Broche 5V de l'Arduino.
  • GND du capteur -> Broche GND de l'Arduino.
  • Sortie gauche (OUT1 ou DO) -> Broche analogique A0.
  • Sortie droite (OUT2 ou DO) -> Broche analogique A1.
Important : N'oubliez jamais de connecter la masse (GND) de la batterie moteur à la masse de l'Arduino. Sans cette liaison, les signaux seront instables et le robot ne fonctionnera pas correctement.

4. La logique de programmation : Le cerveau du robot

La programmation est le cœur du projet. Le principe est simple : lire les capteurs, comparer les valeurs, et ajuster la vitesse des roues. Voici la logique de base pour un suiveur à 2 capteurs :

  • Si les deux capteurs voient du blanc : Le robot avance tout droit.
  • Si le capteur gauche voit du noir : Le robot tourne à gauche (le robot est dévié vers la droite).
  • Si le capteur droit voit du noir : Le robot tourne à droite.
  • Si les deux voient du noir : Le robot s'arrête (fin de piste ou intersection).

Pour une précision accrue, on utilise souvent un PID (Proportionnel, Intégral, Dérivé), mais pour un premier montage, une simple logique "if/else" suffit amplement.

5. Le code Arduino commenté pas à pas

Voici un code fonctionnel et commenté pour votre robot. Copiez-collez ce code dans votre IDE Arduino.

// Définition des broches
const int moteurGaucheAvant = 8;
const int moteurGaucheArriere = 9;
const int moteurDroitAvant = 10;
const int moteurDroitArriere = 11;

const int capteurGauche = A0;
const int capteurDroit = A1;

int vitesseBase = 150; // Vitesse de base (0-255)
int virage = 100; // Vitesse de correction pour les virages

void setup() {
  // Configuration des broches moteurs
  pinMode(moteurGaucheAvant, OUTPUT);
  pinMode(moteurGaucheArriere, OUTPUT);
  pinMode(moteurDroitAvant, OUTPUT);
  pinMode(moteurDroitArriere, OUTPUT);
  
  // Configuration des broches capteurs
  pinMode(capteurGauche, INPUT);
  pinMode(capteurDroit, INPUT);
  
  // Initialisation de la communication série pour le debug
  Serial.begin(9600);
}

void loop() {
  // Lecture des capteurs (0 = noir, 1 = blanc selon le module)
  int valeurGauche = digitalRead(capteurGauche);
  int valeurDroit = digitalRead(capteurDroit);
  
  // Affiche les valeurs dans le moniteur série
  Serial.print("Gauche: ");
  Serial.print(valeurGauche);
  Serial.print(" | Droite: ");
  Serial.println(valeurDroit);
  
  // Logique de suivi de ligne
  if (valeurGauche == 0 && valeurDroit == 0) {
    // Les deux capteurs sur le noir -> stop
    arreter();
  } 
  else if (valeurGauche == 0 && valeurDroit == 1) {
    // Capteur gauche sur noir -> tourner à gauche
    tournerGauche();
  } 
  else if (valeurGauche == 1 && valeurDroit == 0) {
    // Capteur droit sur noir -> tourner à droite
    tournerDroit();
  } 
  else {
    // Les deux capteurs sur blanc -> avancer tout droit
    avancer();
  }
}

void avancer() {
  digitalWrite(moteurGaucheAvant, HIGH);
  digitalWrite(moteurGaucheArriere, LOW);
  digitalWrite(moteurDroitAvant, HIGH);
  digitalWrite(moteurDroitArriere, LOW);
}

void tournerGauche() {
  digitalWrite(moteurGaucheAvant, LOW);
  digitalWrite(moteurGaucheArriere, HIGH);
  digitalWrite(moteurDroitAvant, HIGH);
  digitalWrite(moteurDroitArriere, LOW);
}

void tournerDroit() {
  digitalWrite(moteurGaucheAvant, HIGH);
  digitalWrite(moteurGaucheArriere, LOW);
  digitalWrite(moteurDroitAvant, LOW);
  digitalWrite(moteurDroitArriere, HIGH);
}

void arreter() {
  digitalWrite(moteurGaucheAvant, LOW);
  digitalWrite(moteurGaucheArriere, LOW);
  digitalWrite(moteurDroitAvant, LOW);
  digitalWrite(moteurDroitArriere, LOW);
}
Note : Si votre robot tourne dans le mauvais sens, inversez simplement les fils des moteurs sur le pont en H ou échangez les valeurs dans le code.

6. Réglages et calibrage : L'étape cruciale

Un robot suiveur de ligne nécessite un calibrage minutieux pour fonctionner de manière fluide. Voici les points à vérifier :

  • La hauteur des capteurs : Les capteurs IR doivent être à environ 5 à 10 mm de la surface. Trop haut, ils seront aveugles ; trop bas, ils frotteront.
  • La sensibilité : La plupart des modules TCRT5000 ont un potentiomètre. Tournez-le doucement jusqu'à ce que la LED du capteur s'allume/s'éteigne de manière fiable sur la ligne noire.
  • La vitesse : Commencez avec une vitesse base de 100. Si le robot dévie trop, réduisez la vitesse. Si le robot est trop lent, augmentez-la progressivement.
  • Le contraste de la piste : Utilisez du ruban adhésif noir mat sur un fond blanc brillant. Évitez les surfaces trop réfléchissantes.

7. Dépannage : Les problèmes courants et leurs solutions

Il est rare que tout fonctionne parfaitement du premier coup. Voici un tableau de dépannage rapide :

  • Le robot ne bouge pas : Vérifiez l'alimentation. Les piles sont-elles chargées ? Le pont en H est-il bien alimenté ? L'interrupteur est-il activé ?
  • Le robot avance en cercles : Un moteur est probablement mal câblé ou le capteur correspondant est mal calibré. Vérifiez les connexions OUT1/OUT2 et OUT3/OUT4.
  • Le robot ne réagit pas à la ligne : Le capteur est peut-être trop haut ou le potentiomètre de sensibilité est mal réglé. Testez les valeurs dans le moniteur série pour voir si elles changent.
  • Le robot tremble : La vitesse est trop élevée ou le PID n'est pas bien réglé. Réduisez la vitesse de base.

8. Aller plus loin : Les améliorations possibles

Une fois votre robot fonctionnel, le plaisir ne s'arrête pas là. Voici quelques idées pour pousser le projet plus loin :

  • Ajout d'un PID : Pour une fluidité et une vitesse accrues, implémentez un contrôleur PID. Cela demande plus de code mais le résultat est spectaculaire.
  • Gestion des intersections : Utilisez un capteur à 5 canaux pour détecter les croisements et programmer des actions spécifiques (tourner à droite à la première intersection, etc.).
  • Contrôle à distance : Ajoutez un module Bluetooth HC-05 pour envoyer des commandes de démarrage/arrêt depuis votre smartphone.
  • Affichage OLED : Intégrez un petit écran pour afficher la vitesse, l'état des capteurs ou le nombre de tours effectués.

Conclusion : Votre premier pas dans la robotique autonome

Félicitations ! Vous avez maintenant toutes les clés en main pour construire votre propre robot suiveur de ligne avec Arduino Uno. Ce projet vous a permis de toucher du doigt les concepts fondamentaux de la robotique : la perception (capteurs), la décision (programmation) et l'action (moteurs). N'hésitez pas à expérimenter, à modifier le code et à améliorer votre châssis. Chaque itération vous apprendra quelque chose de nouveau. La robotique est un domaine où l'erreur est une étape d'apprentissage précieuse. Alors, lancez-vous, et amusez-vous à regarder votre création filer le long de la ligne noire avec une précision étonnante !
