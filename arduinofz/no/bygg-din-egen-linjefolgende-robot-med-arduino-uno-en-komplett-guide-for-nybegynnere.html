Bygg din egen linjefølgende robot med Arduino Uno: En komplett guide for nybegynnere

Å bygge en robot er en av de mest givende måtene å lære elektronikk og programmering på. Blant alle robotprosjekter er den linjefølgende roboten (line follower) den perfekte starten. Den er enkel nok for nybegynnere, men samtidig utrolig lærerik. Med en Arduino Uno, noen få sensorer og litt kode, kan du bygge en robot som selvstendig følger en svart linje på et hvitt underlag. I denne guiden går vi gjennom hele prosessen, fra komponentliste til ferdig kode, slik at du kan få din egen robot på bordet i løpet av en helg.

Hva er en linjefølgende robot?

En linjefølgende robot er en autonom maskin som er designet for å følge en visuell linje på bakken. Den bruker optiske sensorer for å lese kontrasten mellom linjen og underlaget. Når sensorene registrerer at roboten er i ferd med å krysse linjen, korrigerer motorene kursen automatisk. Dette konseptet er grunnlaget for mange industrielle applikasjoner, som automatiske transportbånd og selvkjørende vogner i fabrikker.

Hvordan fungerer en linjefølger-sensor?

De fleste DIY-prosjekter bruker infrarøde (IR) sensorer som består av en sender og en mottaker. Senderen sender ut infrarødt lys, og mottakeren måler hvor mye lys som reflekteres tilbake. En svart overflate absorberer mesteparten av lyset, mens en hvit overflate reflekterer nesten alt. Ved å lese denne forskjellen i refleksjon, kan sensoren bestemme om den er over linjen eller på underlaget.

I dette prosjektet bruker vi to sensorer. Hvis begge sensorene ser hvitt, kjører roboten rett fram. Hvis venstre sensor ser svart, svinger roboten venstre. Hvis høyre sensor ser svart, svinger roboten høyre. Dette er kjernen i logikken.

Komplette komponentliste for prosjektet

Før du begynner, må du samle alle delene. Her er en liste over alt du trenger, med anbefalte spesifikasjoner for nybegynnere.

  • Arduino Uno: Hjernen i prosjektet. Du kan også bruke en Arduino Nano eller Mega, men Uno er den enkleste å koble til.
  • IR-sensor modul (2 stk): Kjøp moduler med justerbar potensiometer (typisk KY-033 eller TCRT5000). De gir digitalt signal (0 eller 1) som er lett å lese.
  • L298N motordriver: Denne driveren lar deg styre to DC-motorer med retningskontroll (framover, bakover) og hastighet.
  • 2x DC-motorer med hjul: Velg motorer som kjører på 5-12V. Gummihjul med godt grep er viktig for presisjon.
  • Batteripakke (4x AA eller 9V): Du trenger en separat strømkilde for motorene. Arduinoen kan drives via USB eller samme batteri, men det er tryggest å ha separat strøm til motorene.
  • Robotsjassis: Du kan kjøpe et akryl- eller plastchassis, eller 3D-printe ditt eget. Et enkelt chassis med to lag er ideelt.
  • Jumper-kabler og breadboard: For å gjøre tilkoblingene ryddige.
  • Skruer og muttere: For å feste komponentene til chassiset.

Montering og tilkobling: Steg-for-steg

Når du har alle delene, er det på tide å bygge. Følg denne rekkefølgen for å unngå kortslutninger og feilkoblinger.

1. Fest motorene og hjulene

Skru de to DC-motorene fast til chassiset. Sørg for at de er plassert symmetrisk og at akslingene peker nedover. Fest hjulene på akslingene. Hvis chassiset har en kulelager (ball caster) foran eller bak, monterer du den nå. Dette gir stabil balanse.

2. Monter motordriveren (L298N)

L298N har to kanaler (A og B). Koble motorene til driveren:

  • Venstre motor til OUT1 og OUT2.
  • Høyre motor til OUT3 og OUT4.
  • Koble motorenes strømkilde (batteripakken) til +12V og GND på driveren. Hvis du bruker 4x AA (6V), kan du koble til +5V på driveren for å unngå overbelastning.
  • Koble driverens 5V-utgang til Arduinoens 5V-pin (valgfritt, men nyttig for å drive sensorene).

3. Koble IR-sensorene

Plasser sensorene på fronten av chassiset, med omtrent 3-5 cm mellomrom. De må være lave nok til å se bakken (ca. 1-2 cm over underlaget). Koble dem til Arduinoen:

  • Venstre sensor: VCC til 5V, GND til GND, OUT til digital pin 2.
  • Høyre sensor: VCC til 5V, GND til GND, OUT til digital pin 3.

Juster potensiometeret på hver sensor-modul. Test ved å holde sensoren over hvitt underlag (LED på sensoren skal lyse) og over svart linje (LED skal slukke).

4. Koble motordriveren til Arduinoen

For å styre motorene, må du koble driverens inngangspinner til Arduinoen:

  • IN1 til digital pin 4
  • IN2 til digital pin 5
  • IN3 til digital pin 6
  • IN4 til digital pin 7
  • ENA til digital pin 9 (PWM for hastighet)
  • ENB til digital pin 10 (PWM for hastighet)

For å få hastighetskontroll, må du koble ENA og ENB til PWM-pinner (markert med ~ på Arduinoen).

Fullstendig Arduino-kode for linjefølgeren

Her er en komplett og kommentert kode som fungerer ut av boksen. Kopier og lim inn i Arduino IDE, og last opp til brettet.

// Definer pinner for sensorer
const int sensorVenstre = 2;
const int sensorHoyre = 3;

// Definer pinner for motordriver
const int IN1 = 4;
const int IN2 = 5;
const int IN3 = 6;
const int IN4 = 7;
const int ENA = 9;
const int ENB = 10;

// Hastighet (0-255)
const int hastighet = 180;
const int svingHastighet = 150;

void setup() {
  // Sett sensorpinner som input
  pinMode(sensorVenstre, INPUT);
  pinMode(sensorHoyre, INPUT);
  
  // Sett motorpinner som output
  pinMode(IN1, OUTPUT);
  pinMode(IN2, OUTPUT);
  pinMode(IN3, OUTPUT);
  pinMode(IN4, OUTPUT);
  pinMode(ENA, OUTPUT);
  pinMode(ENB, OUTPUT);
  
  // Start med å stoppe motorene
  stopp();
  delay(2000); // Vent 2 sekunder før start
}

void loop() {
  // Les sensorene (0 = hvit, 1 = svart, avhengig av modul)
  int lesVenstre = digitalRead(sensorVenstre);
  int lesHoyre = digitalRead(sensorHoyre);
  
  // Logikk for linjefølging
  if (lesVenstre == 0 && lesHoyre == 0) {
    // Begge på hvit: kjør rett fram
    kjorFram();
  } 
  else if (lesVenstre == 1 && lesHoyre == 0) {
    // Venstre sensor på linje: sving venstre
    svingVenstre();
  } 
  else if (lesVenstre == 0 && lesHoyre == 1) {
    // Høyre sensor på linje: sving høyre
    svingHoyre();
  } 
  else {
    // Begge på svart: roboten har krysst linjen eller stopp. Stopp.
    stopp();
  }
}

// Motorfunksjoner
void kjorFram() {
  digitalWrite(IN1, HIGH);
  digitalWrite(IN2, LOW);
  digitalWrite(IN3, HIGH);
  digitalWrite(IN4, LOW);
  analogWrite(ENA, hastighet);
  analogWrite(ENB, hastighet);
}

void svingVenstre() {
  digitalWrite(IN1, LOW);
  digitalWrite(IN2, HIGH); // Venstre motor bakover
  digitalWrite(IN3, HIGH);
  digitalWrite(IN4, LOW); // Høyre motor fram
  analogWrite(ENA, svingHastighet);
  analogWrite(ENB, svingHastighet);
}

void svingHoyre() {
  digitalWrite(IN1, HIGH);
  digitalWrite(IN2, LOW); // Venstre motor fram
  digitalWrite(IN3, LOW);
  digitalWrite(IN4, HIGH); // Høyre motor bakover
  analogWrite(ENA, svingHastighet);
  analogWrite(ENB, svingHastighet);
}

void stopp() {
  digitalWrite(IN1, LOW);
  digitalWrite(IN2, LOW);
  digitalWrite(IN3, LOW);
  digitalWrite(IN4, LOW);
  analogWrite(ENA, 0);
  analogWrite(ENB, 0);
}

Kalibrering og tuning: Få roboten til å kjøre perfekt

Etter at du har lastet opp koden, er det på tide å teste. Legg en svart tape-linje (elektriker-tape fungerer godt) på et hvitt gulv eller et stort ark. Plasser roboten på linjen og slå på strømmen. Hvis roboten ikke oppfører seg som forventet, er det tre ting du bør justere:

  • Sensorfølsomhet: Juster potensiometeret på sensorene. Du vil at LED-en på sensoren skal lyse på hvitt og slukke på svart. Hvis det er omvendt, må du justere til det er riktig.
  • Hastighet: Hvis roboten mister linjen i svinger, reduserer du hastigheten i koden (variabelen hastighet). Hvis den kjører for sakte, øker du den.
  • Svingkraft: Hvis roboten overstyrer (svinger for mye), reduserer du svingHastighet. Hvis den understyrer (kjører rett fram i svinger), øker du den.

Vanlige problemer og løsninger

Selv med god kode kan ting gå galt. Her er de vanligste problemene og hvordan du fikser dem.

  • Roboten vibrerer eller hakker: Dette skyldes ofte ustabil strømforsyning. Sørg for at batteriene er fulladet, og at motordriveren og sensorene har separat strøm.
  • Sensorene leser feil: Sjekk at sensorene sitter i riktig høyde. For høyt gir ustabile avlesninger, for lavt kan de skrape i bakken.
  • Motorene beveger seg ikke: Sjekk alle tilkoblinger på L298N. Husk at ENA og ENB må ha PWM-signal (analogWrite) for at motorene skal bevege seg.
  • Roboten kjører bakover: Bytt om på IN1/IN2 eller IN3/IN4 for å reversere motorretningen.

Videreutvikling: Utfordringer og forbedringer

Når den grunnleggende roboten fungerer, kan du utfordre deg selv med flere avanserte funksjoner.

  • Flere sensorer: Legg til en tredje sensor i midten for mer presis styring og høyere hastighet.
  • PID-regulering: Implementer en PID-kontroller for mykere og raskere kurvekjøring. Dette er en klassisk ingeniørøvelse.
  • Hastighetsjustering: Bruk en potensiometer på chassiset for å justere hastigheten i sanntid.
  • Labyrint-løser: Bygg om roboten til å løse en labyrint ved å kombinere linjefølging med avstandssensorer.

Sikkerhet og beste praksis

Selv om dette er et trygt prosjekt, er det noen ting å huske på. Bruk alltid vernebriller når du lodder, selv om de fleste moduler ikke krever lodding. Hold batteriene unna vann og varme. Koble fra strømmen når du endrer på kretsen. Og viktigst av alt: Vær tålmodig. Feilsøking er en del av læringen.

Konklusjon

Gratulerer! Du har nå bygget din egen linjefølgende robot med Arduino Uno. Dette prosjektet har gitt deg grunnleggende kunnskap om sensorer, aktuatorer, motorstyring og logisk programmering. Du har også fått førstehånds erfaring med feilsøking og tuning, som er uvurderlige ferdigheter innen robotikk. Nå som du har mestret dette, er himmelen grensen. Fortsett å eksperimentere, legg til nye sensorer, test nye algoritmer, og viktigst av alt: ha det gøy med å bygge.
