How to Build a Line Follower Robot with Arduino Uno: Complete Step-by-Step Guide

Building a line follower robot is one of the most rewarding and educational projects for anyone venturing into the world of robotics and embedded systems. Using an Arduino Uno as the brain, this project teaches you the fundamentals of sensor integration, motor control, and logic-based decision making. In this comprehensive tutorial, we will walk you through every single step—from gathering components to uploading the final code—so you can assemble your very own autonomous robot that flawlessly tracks a black line on a white surface.

1. Understanding the Line Follower Robot Concept

At its core, a line follower robot is an autonomous machine designed to detect and follow a contrasting line on the floor. The robot uses infrared (IR) sensors to differentiate between the reflective surface (white) and the non-reflective surface (black line). The Arduino continuously reads these sensor values and adjusts the speed of the motors to steer the robot along the path.

The logic is simple: if the left sensor detects the line, the robot turns left; if the right sensor detects it, the robot turns right. When both sensors are on the white surface, the robot moves straight forward. This closed-loop feedback system is the essence of robotics control.

2. Required Components and Materials

Before diving into the assembly, gather all the necessary parts. Here is a complete shopping list:

  • Arduino Uno R3 – The microcontroller board that serves as the robot's brain.
  • L298N Motor Driver Module – Controls the direction and speed of two DC motors.
  • 2x DC Gear Motors with Wheels – Provide the mechanical locomotion.
  • 1x Ball Caster Wheel – Supports the front or rear of the chassis for balance.
  • 2x IR Sensor Modules (TCRT5000) – Detect the line and surface contrast.
  • 7.4V Li-ion Battery or 9V Battery – Powers the Arduino and motors separately.
  • Robot Chassis Kit – Acrylic or plastic base to mount all components.
  • Jumper Wires – For electrical connections.
  • Breadboard (optional) – For prototyping the circuit.
Pro Tip: Ensure the IR sensors have a potentiometer to adjust sensitivity. This is crucial for calibration under different lighting conditions.

3. Circuit Wiring: Connecting Everything

Proper wiring is critical for reliable operation. Follow this connection diagram carefully. We will separate the power and signal lines to avoid interference.

3.1 Power Distribution

Connect the battery positive terminal to the L298N's 12V input. From the L298N's 5V output pin, power the Arduino Uno's 5V pin. This ensures a single power source runs the entire system, with the motor driver regulating voltage for the logic circuits.

3.2 Motor Connections to L298N

  • Left Motor: Connect to OUT1 and OUT2 on the L298N.
  • Right Motor: Connect to OUT3 and OUT4 on the L298N.
  • Enable Pins: Connect ENA to pin 5 and ENB to pin 6 on the Arduino for PWM speed control.
  • Input Pins: Connect IN1 to pin 4, IN2 to pin 7, IN3 to pin 8, and IN4 to pin 9.

3.3 IR Sensor Wiring

  • Left Sensor: VCC to 5V, GND to GND, and OUT to digital pin 2.
  • Right Sensor: VCC to 5V, GND to GND, and OUT to digital pin 3.
Important: Use a common ground between the motor driver, Arduino, and sensors to prevent erratic behavior.

4. Mechanical Assembly of the Chassis

Start by mounting the two DC motors on the chassis base using screws or zip ties. Position them symmetrically on the left and right sides. Attach the wheels to the motor shafts, and fix the ball caster at the front center for stable three-point contact.

Next, mount the Arduino Uno and L298N driver on the chassis using standoffs or double-sided tape. Place the IR sensors on the front underside of the chassis, facing down. They should be positioned approximately 2-3 cm apart, centered on the line path.

Finally, secure the battery pack on the top or bottom, ensuring the center of gravity stays low to prevent tipping during sharp turns.

5. Writing the Arduino Code

Now comes the brain of the operation. Below is a fully commented, production-ready sketch. This code reads the digital output from the sensors and controls the motors accordingly.

// Pin definitions
const int leftSensorPin = 2;
const int rightSensorPin = 3;
const int motorLeftPWM = 5;
const int motorRightPWM = 6;
const int motorLeftIN1 = 4;
const int motorLeftIN2 = 7;
const int motorRightIN3 = 8;
const int motorRightIN4 = 9;

// Speed constants (0-255)
const int baseSpeed = 180;
const int turnSpeed = 140;

void setup() {
  pinMode(leftSensorPin, INPUT);
  pinMode(rightSensorPin, INPUT);
  pinMode(motorLeftIN1, OUTPUT);
  pinMode(motorLeftIN2, OUTPUT);
  pinMode(motorRightIN3, OUTPUT);
  pinMode(motorRightIN4, OUTPUT);
  pinMode(motorLeftPWM, OUTPUT);
  pinMode(motorRightPWM, OUTPUT);
  // Initial stop
  stopMotors();
}

void loop() {
  int leftSensor = digitalRead(leftSensorPin);
  int rightSensor = digitalRead(rightSensorPin);

  // Sensor logic: 0 = black line detected, 1 = white surface
  if (leftSensor == LOW && rightSensor == HIGH) {
    // Left sensor on line, turn left
    turnLeft();
  } 
  else if (leftSensor == HIGH && rightSensor == LOW) {
    // Right sensor on line, turn right
    turnRight();
  } 
  else if (leftSensor == LOW && rightSensor == LOW) {
    // Both on line (intersection), go straight
    moveForward();
  } 
  else {
    // Both on white (lost), stop or search
    stopMotors();
    delay(100);
    moveForward();
  }
}

void moveForward() {
  digitalWrite(motorLeftIN1, HIGH);
  digitalWrite(motorLeftIN2, LOW);
  digitalWrite(motorRightIN3, HIGH);
  digitalWrite(motorRightIN4, LOW);
  analogWrite(motorLeftPWM, baseSpeed);
  analogWrite(motorRightPWM, baseSpeed);
}

void turnLeft() {
  digitalWrite(motorLeftIN1, LOW);
  digitalWrite(motorLeftIN2, HIGH);
  digitalWrite(motorRightIN3, HIGH);
  digitalWrite(motorRightIN4, LOW);
  analogWrite(motorLeftPWM, turnSpeed);
  analogWrite(motorRightPWM, turnSpeed);
}

void turnRight() {
  digitalWrite(motorLeftIN1, HIGH);
  digitalWrite(motorLeftIN2, LOW);
  digitalWrite(motorRightIN3, LOW);
  digitalWrite(motorRightIN4, HIGH);
  analogWrite(motorLeftPWM, turnSpeed);
  analogWrite(motorRightPWM, turnSpeed);
}

void stopMotors() {
  digitalWrite(motorLeftIN1, LOW);
  digitalWrite(motorLeftIN2, LOW);
  digitalWrite(motorRightIN3, LOW);
  digitalWrite(motorRightIN4, LOW);
  analogWrite(motorLeftPWM, 0);
  analogWrite(motorRightPWM, 0);
}

Upload this code to your Arduino Uno using the Arduino IDE. Ensure you select the correct board and COM port.

6. Calibration and Testing

Calibration is the difference between a robot that works and one that spins in circles. Place the robot on a test track with a 2cm thick black line on a white background.

6.1 Adjusting Sensor Sensitivity

Using a small screwdriver, turn the potentiometer on each IR sensor. Place the sensor over the white surface and adjust until the LED on the sensor goes off. Then place it over the black line and confirm the LED lights up. Repeat for the second sensor.

6.2 Speed Tuning

Start with a base speed of 150. If the robot overshoots the line, reduce the speed. If it moves too slowly, increase the speed incrementally. The turn speed should always be slightly lower than base speed for stable curves.

7. Troubleshooting Common Issues

  • Robot doesn't move: Check battery voltage, verify motor driver power LED is lit, and confirm all ground connections.
  • Robot vibrates or jerks: This indicates unstable power. Add a 1000µF capacitor across the motor power terminals.
  • Sensors not detecting line: Lower the sensors closer to the ground (5-10mm) or increase the potentiometer sensitivity.
  • Robot goes straight but misses curves: Increase the distance between the two sensors to improve line detection angle.
  • Code uploads but nothing happens: Recheck the wiring against the pin definitions in the code.

8. Advanced Enhancements and Ideas

Once your basic line follower works flawlessly, consider these upgrades to push your skills further:

  • PID Control: Implement a proportional-integral-derivative algorithm for ultra-smooth tracking at high speeds.
  • OLED Display: Show live sensor values and speed metrics for debugging.
  • Bluetooth Control: Add an HC-05 module to switch between line-following and manual smartphone control.
  • Multiple Sensors: Use an array of 5-8 IR sensors to handle sharp 90-degree turns and intersections.
  • Obstacle Avoidance: Integrate an ultrasonic sensor to stop the robot when an object blocks the path.

The logic you implemented here—reading inputs, making decisions, and driving outputs—is the same foundation used in industrial automation, autonomous vehicles, and advanced robotics.

Don't stop here. Experiment with different track layouts, tweak the code, and add new features. Every modification teaches you something new about the beautiful intersection of hardware and software. Happy building!
