Arduino-robotti: Viivanseuraajarobotin rakentaminen Arduino Unolla – Täydellinen opas aloittelijoille

Robotiikka on yksi kiehtovimmista tavoista oppia elektroniikkaa ja ohjelmointia käytännössä. Erityisesti viivanseuraajarobotti (line follower) on klassikkoprojekti, joka yhdistää anturit, moottorit ja logiikan yksinkertaisella mutta opettavaisella tavalla. Tässä kattavassa oppaassa rakennamme toimivan viivanseuraajarobotin käyttäen Arduino Uno -kehitysalustaa. Käymme läpi kaiken tarvittavista komponenteista aina lopulliseen testaukseen ja hienosäätöön asti.

Mitä tarvitset viivanseuraajarobotin rakentamiseen?

Ennen kuin aloitamme, varmista, että sinulla on seuraavat komponentit. Suurin osa näistä löytyy edullisista aloittelijapaketeista.

  • Arduino Uno (tai yhteensopiva klooni)
  • 2 kpl DC-moottoria vaihteistolla (esim. TT-moottorit) ja pyörät
  • L298N-moottorikortti tai L293D (moottorien ohjaukseen)
  • 2–5 kpl TCRT5000-infrapuna-anturia (viivan tunnistukseen)
  • Akustoksi 4x AA-paristot tai 7,4V LiPo-akku
  • Leipälevy ja hyppyjohtoja
  • Robottialusta (esim. akryyli- tai 3D-tulostettu runko)
  • Ruuvimeisseli, kaapelinsiteet ja tarvittaessa juotosvälineet

Vinkki: Jos et halua rakentaa runkoa alusta asti, voit ostaa valmiin 2WD- tai 4WD-robottialustan, johon on helppo kiinnittää Arduino ja anturit.

Kuinka viivanseuraajarobotti toimii?

Toimintaperiaate on loppujen lopuksi hyvin yksinkertainen. Robotti käyttää infrapuna-antureita, jotka on asennettu sen etuosaan lähelle alustaa. Anturi lähettää infrapunavaloa ja mittaa heijastuneen valon määrää.

  • Vaalea pinta (esim. valkoinen lattia) heijastaa hyvin infrapunavaloa takaisin anturille.
  • Tumma pinta (esim. musta teippi) imee infrapunavaloa, jolloin heijastus on heikko.

Arduino lukee näitä arvoja ja vertaa niitä ennalta määritettyyn kynnysarvoon. Kun robotti huomaa, että se on ajautumassa pois viivalta, se säätää moottorien nopeuksia – toinen pyörä pyörii nopeammin ja toinen hitaammin – jolloin se kääntyy takaisin viivalle. Tämä on klassinen PID-säätö tai yksinkertaisempi on/off-ohjaus.

Anturien asennus ja kytkentä

Anturien sijoittelu on kriittistä toiminnan kannalta. Suosittelen käyttämään vähintään kahta anturia (vasen ja oikea), mutta kolmen tai viiden anturin sarja antaa tarkemman luennan ja mahdollistaa sulavammat käännökset.

Tässä esimerkissä käytämme kolmea TCRT5000-anturia. Ne asennetaan siten, että keskimmäinen anturi on suoraan viivan päällä ja sivuanturit hieman sen ulkopuolella.

Kytkentäkaavio (Arduino Uno + L298N + 3 anturia)

Alla on selkeä kytkentäohje. Muista tarkistaa omien moduuliesi pinnijärjestys, sillä ne voivat vaihdella valmistajan mukaan.

  • TCRT5000-moduulit: VCC → 5V (Arduino), GND → GND, OUT → Arduino-digitaalipinnit (esim. D2, D3, D4)
  • L298N-moottorikortti: VCC → 7-12V (akusta), GND → GND (jaettu Arduinon kanssa), 5V (ulostulo, jos tarvitaan), IN1→D5, IN2→D6, IN3→D10, IN4→D11, ENA→D9 (PWM), ENB→D5 (PWM)
  • Moottorit: Moottori A → L298N:n OUT1 ja OUT2, Moottori B → OUT3 ja OUT4

Huomio: L298N-kortin 5V-lähdöstä voi ottaa virran Arduinolle, mutta jos käytät erillistä virtalähdettä Arduinolle, varmista, että GND:t on kytketty yhteen. Muuten signaalit eivät toimi.

Arduino-ohjelmakoodi (Sketch) viivanseuraajalle

Nyt päästään itse ohjelmointiin. Tämä koodi on suunniteltu kolmelle anturille ja se käyttää yksinkertaista logiikkaa. Voit kopioida sen suoraan Arduino IDE:hen ja ladata sen levylle.

Tässä on täydellinen ja kommentoitu koodi:

// Määritellään pinnit
const int sensoriVasen = 2;
const int sensoriKeski = 3;
const int sensoriOikea = 4;

// Moottorikortin pinnit
const int enA = 9;
const int in1 = 5;
const int in2 = 6;
const int in3 = 10;
const int in4 = 11;
const int enB = 12;

// Perusnopeus (0-255)
int perusNopeus = 180;
int kaannosNopeus = 120;

void setup() {
  // Alustetaan anturipinnit
  pinMode(sensoriVasen, INPUT);
  pinMode(sensoriKeski, INPUT);
  pinMode(sensoriOikea, INPUT);

  // Alustetaan moottoripinnit
  pinMode(enA, OUTPUT);
  pinMode(enB, OUTPUT);
  pinMode(in1, OUTPUT);
  pinMode(in2, OUTPUT);
  pinMode(in3, OUTPUT);
  pinMode(in4, OUTPUT);

  // Pysäytetään moottorit aluksi
  digitalWrite(in1, LOW);
  digitalWrite(in2, LOW);
  digitalWrite(in3, LOW);
  digitalWrite(in4, LOW);

  Serial.begin(9600); // Testausta varten
}

void loop() {
  // Luetaan anturit (0 = tumma pinta, 1 = vaalea pinta)
  int vasen = digitalRead(sensoriVasen);
  int keski = digitalRead(sensoriKeski);
  int oikea = digitalRead(sensoriOikea);

  // Logiikka: keskimmäinen anturi viivalla = mene suoraan
  if (keski == 1 && vasen == 0 && oikea == 0) {
    // Mene suoraan
    ajaSuoraan();
  }
  // Jos vasen anturi osuu viivalle, käänny vasemmalle
  else if (vasen == 1) {
    kaannyVasemmalle();
  }
  // Jos oikea anturi osuu viivalle, käänny oikealle
  else if (oikea == 1) {
    kaannyOikealle();
  }
  // Jos mikään anturi ei näe viivaa (esim. mutka), pysähdy tai etsi
  else {
    pysahdy();
    delay(50); // Pieni viive, jotta robotti ei pyöri paikallaan
  }
}

void ajaSuoraan() {
  digitalWrite(in1, HIGH);
  digitalWrite(in2, LOW);
  digitalWrite(in3, HIGH);
  digitalWrite(in4, LOW);
  analogWrite(enA, perusNopeus);
  analogWrite(enB, perusNopeus);
}

void kaannyVasemmalle() {
  // Vasen pyörä pysähtyy, oikea pyörii
  digitalWrite(in1, LOW);
  digitalWrite(in2, LOW);
  digitalWrite(in3, HIGH);
  digitalWrite(in4, LOW);
  analogWrite(enA, 0);
  analogWrite(enB, kaannosNopeus);
}

void kaannyOikealle() {
  // Oikea pyörä pysähtyy, vasen pyörii
  digitalWrite(in1, HIGH);
  digitalWrite(in2, LOW);
  digitalWrite(in3, LOW);
  digitalWrite(in4, LOW);
  analogWrite(enA, kaannosNopeus);
  analogWrite(enB, 0);
}

void pysahdy() {
  digitalWrite(in1, LOW);
  digitalWrite(in2, LOW);
  digitalWrite(in3, LOW);
  digitalWrite(in4, LOW);
  analogWrite(enA, 0);
  analogWrite(enB, 0);
}

Koodin selitys ja hienosäätö

Yllä oleva koodi on perusversio. Se toimii, mutta se voi olla nykivä nopeissa mutkissa. Tässä muutamia parannusideoita:

  • PID-säätö: Käytä analogisia antureita (A0-A2) ja laske virhe, jonka perusteella säädät moottorien nopeutta portaattomasti. Tämä tekee liikkeestä erittäin sulavaa.
  • Nopeuden säätö: Kokeile eri perusNopeus-arvoja. Liian suuri nopeus saa robotin sinkoilemaan, liian pieni taas tekee siitä hitaan.
  • Anturien kalibrointi: Ympäristön valo vaikuttaa antureihin. Lisää koodiin kalibrointivaihe, joka mittaa valaistuksen alussa ja asettaa kynnysarvot automaattisesti.

Radan suunnittelu ja testaus

Kun robotti on kasattu ja koodi ladattu, on aika testata sitä. Suosittelen aloittamaan yksinkertaisella radalla, joka on tehty mustalla eriste teipillä valkoiselle lattialle tai kartongille.

  • Aloita suoralla: Tarkista, että robotti kulkee suoraan. Jos se vetää toiselle puolelle, säädä moottorien nopeuksia (esim. pienennä toisen moottorin nopeutta).
  • Lisää mutkia: Tee loivia mutkia ja tarkkaile, miten robotti reagoi. Jos se ajautuu ulos, lisää kaannosNopeutta tai hidasta perusNopeutta.
  • Testaa jyrkkiä mutkia: Jyrkissä mutkissa voi olla tarpeen käyttää pyörähdyskäännöstä (toinen pyörä taaksepäin). Kokeile muokata koodia.

Vianetsintä: Jos robotti ei reagoi lainkaan, tarkista ensin johdotukset ja virtalähteet. Yleisin virhe on, että GND:t eivät ole yhteisiä tai että moottorikortti ei saa tarpeeksi virtaa. Mittaa myös anturien lähdöt yleismittarilla varmistaaksesi, että ne vaihtuvat viivan yli ajettaessa.

Laajennusideoita ja seuraavat askeleet

Onnittelut, olet nyt rakentanut toimivan viivanseuraajarobotin! Tästä on hyvä jatkaa. Tässä muutamia ideoita, miten voit viedä projektia pidemmälle:

  • Lisää antureita: Viiden anturin sarja mahdollistaa tarkemman PID-säädön ja nopeammat ajot.
  • Bluetooth-ohjaus: Lisää HC-05-moduuli ja ohjaa robottia puhelimella.
  • Esteiden tunnistus: Lisää ultraäänianturi (HC-SR04) ja opeta robotti pysähtymään esteen eteen.
  • Kilparata: Osallistu paikallisiin robottikilpailuihin ja optimoi robottisi nopeus ja tarkkuus.

Muista, että oppiminen tapahtuu kokeilemalla ja virheistä oppimalla. Älä pelkää rikkoa asioita – se on osa prosessia!
