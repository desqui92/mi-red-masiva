Guía Definitiva: Cómo Construir un Robot Seguidor de Línea con Arduino Uno

¿Alguna vez has soñado con construir tu propio robot? El robot seguidor de línea es, sin duda, el proyecto perfecto para iniciarte en el mundo de la robótica. No solo es visualmente impresionante, sino que te enseña los fundamentos de la electrónica, la programación y el control de motores. En esta guía completa, te mostraré paso a paso cómo ensamblar y programar tu propio seguidor de línea utilizando el icónico Arduino Uno. Olvídate de la teoría aburrida; aquí vamos a la acción.

¿Qué es un Robot Seguidor de Línea y Cómo Funciona?

Un robot seguidor de línea es un vehículo autónomo capaz de detectar y seguir una línea dibujada en el suelo, generalmente de color negro sobre una superficie blanca (o viceversa). Su funcionamiento se basa en un principio simple pero efectivo: la retroalimentación por sensores.

El cerebro del sistema, nuestro Arduino Uno, lee constantemente las señales de los sensores infrarrojos (IR). Estos sensores emiten luz infrarroja y miden la cantidad que rebota. La superficie blanca refleja más luz que la negra, lo que genera una diferencia de voltaje que el Arduino interpreta como "1" o "0". Con esta información, el microcontrolador decide qué motor debe girar más rápido o más lento para corregir el rumbo y mantenerse sobre la línea.

Lista de Materiales Necesarios para tu Robot

Antes de empezar a soldar o conectar cables, asegúrate de tener todos los componentes. Esta es la lista definitiva para construir un robot robusto y funcional:

  • Placa de desarrollo: Arduino Uno (o un clon compatible).
  • Chasis del robot: Puedes comprar uno de acrílico o imprimirlo en 3D. También sirve una base de plástico rígido.
  • Puente H (Driver de motores): L298N o L293D (el L298N es más fácil para principiantes).
  • Motores con reductora: 2 motores DC de 3-6V con ruedas.
  • Rueda loca: Una rueda giratoria (ball caster) para el equilibrio.
  • Sensores de línea: Módulo seguidor de línea TCRT5000 (recomendado) o 2 sensores infrarrojos individuales.
  • Batería: Power bank (5V) o pack de 4 pilas AA (6V).
  • Cables jumper: Macho-macho y macho-hembra.
  • Destornillador, cinta aislante y bridas.

Paso 1: Ensamblaje del Hardware y las Conexiones

La parte más delicada es el cableado. Un error aquí puede quemar tu placa. Sigue este esquema al pie de la letra:

Conexión del Puente H (L298N)

El puente H actúa como un intermediario entre el Arduino y los motores, ya que los motores consumen más corriente de la que el Arduino puede suministrar.

  • Motores: Conecta el motor izquierdo a OUT1 y OUT2. Conecta el motor derecho a OUT3 y OUT4.
  • Alimentación: Conecta el pin 12V del L298N al positivo de la batería (o al pin 5V del Arduino si usas power bank, aunque es mejor alimentarlo directo). Conecta el pin GND del L298N al GND del Arduino y al negativo de la batería.
  • Pines de control: Conecta IN1 a D8, IN2 a D9, IN3 a D10 e IN4 a D11 en el Arduino.

Conexión de los Sensores de Línea

El módulo TCRT5000 suele tener 5 pines: VCC, GND, y dos salidas digitales (OUT1, OUT2) o una salida analógica. Para este tutorial usaremos las salidas digitales.

  • VCC: Conéctalo al pin 5V del Arduino.
  • GND: Conéctalo al GND del Arduino.
  • OUT Izquierdo: Conéctalo al pin digital A0 (puedes usar cualquier pin digital, pero A0 es ideal).
  • OUT Derecho: Conéctalo al pin digital A1.
Consejo profesional: Calibra la sensibilidad del sensor con el potenciómetro integrado en el módulo. Gíralo lentamente hasta que el LED del sensor se encienda sobre la superficie blanca y se apague sobre la línea negra.

Paso 2: Lógica de Programación en Arduino

La lógica es un sencillo "si... entonces". Si el sensor izquierdo detecta blanco y el derecho detecta negro, significa que el robot se está desviando a la derecha, por lo que debemos girar a la izquierda.

Aquí tienes el código completo y comentado para copiar y pegar en tu IDE de Arduino:

// Pines de los motores
#define ENA 5  // Pin de velocidad motor A (izquierdo)
#define ENB 6  // Pin de velocidad motor B (derecho)
#define IN1 8
#define IN2 9
#define IN3 10
#define IN4 11

// Pines de los sensores
#define SENSOR_IZQ A0
#define SENSOR_DER A1

void setup() {
  pinMode(IN1, OUTPUT);
  pinMode(IN2, OUTPUT);
  pinMode(IN3, OUTPUT);
  pinMode(IN4, OUTPUT);
  pinMode(ENA, OUTPUT);
  pinMode(ENB, OUTPUT);
  pinMode(SENSOR_IZQ, INPUT);
  pinMode(SENSOR_DER, INPUT);
}

void loop() {
  int izq = digitalRead(SENSOR_IZQ);
  int der = digitalRead(SENSOR_DER);

  // Caso 1: Ambos sensores en blanco (fuera de línea) -> Ir hacia adelante
  if (izq == HIGH && der == HIGH) {
    adelante();
  }
  // Caso 2: Solo sensor izquierdo en negro -> Girar a la izquierda
  else if (izq == LOW && der == HIGH) {
    girarIzquierda();
  }
  // Caso 3: Solo sensor derecho en negro -> Girar a la derecha
  else if (izq == HIGH && der == LOW) {
    girarDerecha();
  }
  // Caso 4: Ambos en negro (línea gruesa o cruce) -> Detenerse o seguir recto
  else {
    detener();
  }
}

void adelante() {
  digitalWrite(IN1, HIGH);
  digitalWrite(IN2, LOW);
  digitalWrite(IN3, HIGH);
  digitalWrite(IN4, LOW);
  analogWrite(ENA, 150); // Velocidad izquierda
  analogWrite(ENB, 150); // Velocidad derecha
}

void girarIzquierda() {
  digitalWrite(IN1, LOW);
  digitalWrite(IN2, HIGH);
  digitalWrite(IN3, HIGH);
  digitalWrite(IN4, LOW);
  analogWrite(ENA, 100);
  analogWrite(ENB, 150);
}

void girarDerecha() {
  digitalWrite(IN1, HIGH);
  digitalWrite(IN2, LOW);
  digitalWrite(IN3, LOW);
  digitalWrite(IN4, HIGH);
  analogWrite(ENA, 150);
  analogWrite(ENB, 100);
}

void detener() {
  digitalWrite(IN1, LOW);
  digitalWrite(IN2, LOW);
  digitalWrite(IN3, LOW);
  digitalWrite(IN4, LOW);
}

Paso 3: Calibración y Ajustes de Velocidad

Cada robot es un mundo. El código anterior es un punto de partida, pero es probable que tengas que ajustar los valores de velocidad (los números en analogWrite).

  • Si el robot vibra o zigzaguea demasiado: Reduce la velocidad base (cambia 150 por 120).
  • Si no gira lo suficiente en las curvas: Aumenta la diferencia de velocidad entre los motores (por ejemplo, 100 y 180).
  • Si los motores no se mueven: Verifica que el puente H esté recibiendo 5V en el pin VCC para la lógica interna.

Problemas Comunes y Soluciones (Troubleshooting)

Es normal que a la primera no funcione perfecto. Aquí tienes una guía rápida de errores:

Síntoma Posible Causa y Solución
Los motores no giran Revisa la alimentación. El puente H necesita al menos 6V en la entrada de potencia. ¿Está el jumper del L298N quitado si usas batería externa?
El robot ignora la línea negra La sensibilidad del sensor está mal calibrada. Gira el potenciómetro hasta que el LED de detección cambie de estado sobre la línea.
El robot se mueve en círculos Uno de los motores está mal conectado en el puente H. Intercambia los cables de OUT1/OUT2 o OUT3/OUT4.

Conclusión y Mejoras Futuras

¡Felicidades! Has construido tu primer robot autónomo. Este proyecto no solo te da una base sólida en robótica, sino que es el punto de partida para crear máquinas más complejas. Ahora que domina lo básico, puedes intentar:

  • Robot con control PID: Implementa un controlador PID para que el movimiento sea más suave y preciso, ideal para curvas cerradas.
  • Agregar Bluetooth: Conecta un módulo HC-05 para controlar el robot manualmente desde tu smartphone.
  • Sensor de ultrasonido: Añade un HC-SR04 para que evite obstáculos mientras sigue la línea.

La robótica es un viaje emocionante. No te detengas aquí. Desarma, modifica y vuelve a armar. La práctica es la única forma de convertirte en un verdadero maker. ¡Nos vemos en el próximo tutorial!
