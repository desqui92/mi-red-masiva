Arduino Robot Seguidor de Línea: Guía Completa con Arduino Uno

El mundo de la robótica educativa ha encontrado en Arduino su mejor aliado. Entre los proyectos más populares y gratificantes para principiantes y aficionados se encuentra el robot seguidor de línea con Arduino Uno. Este proyecto no solo es fascinante de ver en acción, sino que también te enseña los fundamentos de la electrónica, la programación y el control de motores. En esta guía definitiva, te explicaremos paso a paso cómo construir tu propio robot capaz de seguir una línea negra sobre una superficie blanca (o viceversa), utilizando componentes accesibles y código claro.

¿Qué es un Robot Seguidor de Línea?

Un robot seguidor de línea es un vehículo autónomo diseñado para detectar y seguir una línea marcada en el suelo. Su funcionamiento se basa en un principio simple: utiliza sensores ópticos (generalmente infrarrojos) para leer el contraste entre la superficie y la línea. El cerebro del sistema, un Arduino Uno, procesa esta información y ordena a los motores girar a la derecha o a la izquierda para corregir la trayectoria y mantenerse sobre el camino trazado.

Este tipo de robot es la base de competiciones como la "Line Follower Race" y es perfecto para entender conceptos como:

  • Lógica de control (control proporcional o PID).
  • Lectura de sensores analógicos y digitales.
  • Control de motores DC con puente H.
  • Calibración de sensores.

Lista de Materiales Necesarios

Antes de comenzar a soldar o conectar cables, asegúrate de tener todos los componentes. Esta es la lista básica para un robot funcional:

  • Placa Arduino Uno: el cerebro del robot.
  • Chasis o base: puede ser de acrílico, madera o incluso impreso en 3D.
  • 2 Motores DC con reductora (idealmente de 3V a 6V) con ruedas.
  • Rueda loca (para el tercer punto de apoyo).
  • Puente H L298N o L293D: módulo para controlar la dirección y velocidad de los motores.
  • Módulo sensor de línea (TCRT5000 o KY-033): es recomendable usar un módulo con 2 o 3 sensores para una mejor detección.
  • Batería: 4 pilas AA o una batería LiPo de 7.4V.
  • Cables jumper (macho-macho y macho-hembra).
  • Destornillador y cinta aislante o bridas.

Montaje del Hardware: Paso a Paso

El montaje físico es crucial. Un robot con las ruedas mal alineadas o los sensores demasiado altos no funcionará correctamente. Sigue estos pasos:

1. Preparación del Chasis

Fija los dos motores DC a los laterales del chasis. Asegúrate de que las ruedas queden perfectamente paralelas entre sí. Coloca la rueda loca en la parte frontal o trasera (dependiendo del diseño) para equilibrar el peso. La distancia entre los sensores y el suelo debe ser de 0.5 cm a 1.5 cm; esta es la distancia óptima para que el sensor TCRT5000 funcione correctamente.

2. Conexión del Puente H (L298N)

El puente H es el encargado de suministrar la corriente necesaria a los motores, ya que el Arduino no puede hacerlo directamente. La conexión típica es la siguiente:

  • Motor A: conecta los cables del motor izquierdo a OUT1 y OUT2.
  • Motor B: conecta los cables del motor derecho a OUT3 y OUT4.
  • VCC del L298N: a la alimentación positiva de la batería (7V a 12V).
  • GND del L298N: a tierra de la batería y también al GND del Arduino (importante para la referencia de voltaje).
  • 5V del L298N: (si tienes el jumper puesto) puede alimentar el Arduino, pero es más seguro usar la fuente del propio Arduino.
  • IN1, IN2, IN3, IN4: pines de control conectados a los pines digitales del Arduino (ej. 4,5,6,7).
  • ENA y ENB: pines de habilitación. Si no usas PWM, conéctalos a 5V (o déjalos con el jumper puesto para máxima velocidad).

3. Conexión de los Sensores de Línea

Para simplificar, usaremos un módulo de sensores con 2 o 3 canales. La conexión es sencilla:

  • VCC: al pin 5V del Arduino.
  • GND: al pin GND del Arduino.
  • OUT1 (Izquierdo): al pin digital 8 del Arduino.
  • OUT2 (Derecho): al pin digital 9 del Arduino.

Si tu módulo tiene salida analógica, puedes usar pines analógicos para una calibración más fina (A0 y A1).

El Código del Robot: Lógica de Control

La lógica de un seguidor de línea simple se basa en una tabla de verdad. Si la línea es negra sobre blanco, los sensores leerán LOW (0) cuando estén sobre la línea y HIGH (1) cuando estén sobre la superficie blanca. El código más básico sería:

Lógica básica: Si el sensor izquierdo detecta línea, el robot debe girar a la izquierda (motor derecho más rápido). Si el sensor derecho detecta línea, gira a la derecha (motor izquierdo más rápido). Si ambos detectan línea (cruce), avanza en línea recta.

Aquí tienes un ejemplo de código funcional para probar tu robot:


// Definición de pines
const int sensorIzq = 8;
const int sensorDer = 9;

// Pines del puente H
const int in1 = 4;
const int in2 = 5;
const int in3 = 6;
const int in4 = 7;

int velBase = 150; // Velocidad base (0-255)

void setup() {
  pinMode(sensorIzq, INPUT);
  pinMode(sensorDer, INPUT);
  pinMode(in1, OUTPUT);
  pinMode(in2, OUTPUT);
  pinMode(in3, OUTPUT);
  pinMode(in4, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int lecturaIzq = digitalRead(sensorIzq);
  int lecturaDer = digitalRead(sensorDer);

  // Caso 1: Ambos sensores sobre blanco (0,0) -> Avanzar
  if (lecturaIzq == LOW && lecturaDer == LOW) {
    adelante();
  }
  // Caso 2: Solo izquierdo sobre línea (1,0) -> Girar a la izquierda
  else if (lecturaIzq == HIGH && lecturaDer == LOW) {
    girarIzquierda();
  }
  // Caso 3: Solo derecho sobre línea (0,1) -> Girar a la derecha
  else if (lecturaIzq == LOW && lecturaDer == HIGH) {
    girarDerecha();
  }
  // Caso 4: Ambos sobre línea (1,1) -> Detenerse o avanzar (cruce)
  else {
    detener();
  }
}

// Funciones de movimiento
void adelante() {
  digitalWrite(in1, HIGH);
  digitalWrite(in2, LOW);
  digitalWrite(in3, HIGH);
  digitalWrite(in4, LOW);
  analogWrite(10, velBase); // ENA
  analogWrite(11, velBase); // ENB
}

void girarIzquierda() {
  digitalWrite(in1, LOW);
  digitalWrite(in2, LOW);
  digitalWrite(in3, HIGH);
  digitalWrite(in4, LOW);
  analogWrite(10, 0);
  analogWrite(11, velBase);
}

void girarDerecha() {
  digitalWrite(in1, HIGH);
  digitalWrite(in2, LOW);
  digitalWrite(in3, LOW);
  digitalWrite(in4, LOW);
  analogWrite(10, velBase);
  analogWrite(11, 0);
}

void detener() {
  digitalWrite(in1, LOW);
  digitalWrite(in2, LOW);
  digitalWrite(in3, LOW);
  digitalWrite(in4, LOW);
}

Nota importante: Este código usa PWM en los pines 10 y 11 para controlar la velocidad. Si usas un L298N, asegúrate de que los jumpers de ENA y ENB estén quitados para usar el control por PWM.

Calibración y Ajustes Finos

Es muy probable que tu robot no funcione perfectamente a la primera. La calibración es el secreto para un buen desempeño. Sigue estos consejos:

  • Altura del sensor: Si el robot tiembla o no detecta bien, baja o sube los sensores. La distancia ideal es justo donde el LED del sensor parpadea claramente al pasar sobre la línea.
  • Velocidad: Empieza con una velocidad baja (velBase = 100) y ve aumentando gradualmente. Un robot rápido es difícil de controlar con una lógica simple.
  • Contraste: Asegúrate de que la línea sea de un color mate (negro mate es ideal) y el fondo sea blanco brillante. Evita reflejos que confundan al sensor.
  • Curvas: Si tu circuito tiene curvas cerradas, necesitarás usar 3 o más sensores para una detección más precisa de la posición.

Mejoras Avanzadas: Control PID

Si ya dominas el control básico y quieres que tu robot sea más rápido y suave, es hora de implementar un controlador PID (Proporcional-Integral-Derivativo). En lugar de solo leer si los sensores están o no sobre la línea, usarás un sensor de array lineal (como el de 8 sensores) para obtener un valor de error proporcional a la desviación del robot. Este valor se introduce en la fórmula PID para ajustar la velocidad de los motores de forma dinámica, reduciendo las oscilaciones y permitiendo velocidades mucho mayores.

El PID es un tema avanzado, pero los resultados son espectaculares. Para ello necesitarás:

  • Un sensor de línea con array de 8 canales (como el QTR-8A).
  • Una librería de Arduino como QTRSensors.
  • Conocimientos de cálculo y ajuste de constantes (Kp, Ki, Kd).

Consejos Finales y Solución de Problemas

Para concluir, aquí tienes una lista de problemas comunes y sus soluciones:

  • Los motores no giran: Revisa la alimentación del L298N. ¿Está el jumper de 5V colocado? ¿La batería está cargada?
  • El robot solo va hacia adelante: Revisa las conexiones de IN1 a IN4. Asegúrate de que no haya cables sueltos.
  • El robot zigzaguea mucho: Baja la velocidad base o reduce el contraste de la línea. También puedes revisar la alineación de las ruedas.
  • Los sensores no detectan nada: Verifica que el VCC y GND de los sensores estén correctamente conectados. Mide la distancia al suelo con una regla.

No solo terminarás con un robot funcional, sino con un profundo entendimiento de cómo interactúan el hardware y el software. No te desanimes si los primeros intentos fallan; la depuración es parte del proceso. ¡Anímate a experimentar con diferentes diseños de pista, velocidades y algoritmos de control!
